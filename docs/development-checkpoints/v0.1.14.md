# Copy APP v0.1.14: direct TrollStore helper launch on iOS 16

[English](v0.1.14.md) · [简体中文](v0.1.14.zh-CN.md)

This release changes the iPhone XR TrollStore install path. Copy APP still pins the USB device, SSH host key, helper location and staged IPA hash, and stops only a verified matching App process. It now spawns the installed TrollStore helper directly through the root Frida connection. The installer confirms effective UID 0, waits for that exact helper process to exit, and checks the requested Bundle ID, version and build through InstallationProxy. A timeout records the stop request and the immediately observed installed version; the install command is never automatically retried. `copyapp verify` checks the saved direct-process evidence as well as the IPA snapshot. Existing shell-path install cases remain verifiable.

The change addresses a reproduced XR failure mode: the older shell-wrapped helper path timed out twice updating the Podcasts clone to build 2 and once updating to build 4, leaving the old build installed. A no-argument startup probe returned successfully before the build-4 install still stalled. A separate direct-process diagnostic then installed build 4. With the released direct path, versioned builds 5 and 6 each installed on the first attempt, including an update after the clone was used in the foreground. Both installed builds were checked against the saved IPA. The same source was development-signed and upgraded through USB on iPhone 14 / iOS 17.3.1; its build-5 and build-6 updates also passed on the first attempt.

Build 5 passed the saved Library, Search and Listen Now clone playbooks on both phones (six complete, verifiable cases). Build 6 launched on both phones with matching frontmost Bundle IDs and version/build 0.1.5 (6). The earlier original-versus-clone Podcasts delivery remains a **selected navigation result with major visual gaps**; these upgrade regressions do not convert it into a full replica. The direct helper path cannot capture the helper's exit code or stdout, so success is based on root identity, process exit and exact installed-package observation. Two formal XR updates do not establish long-run first-attempt reliability. iOS 26, arbitrary Apps, autonomous unfamiliar-App source generation, a standalone Claude CLI run, long Clock interruptions and complete sandbox/network interpretation remain outside this release's verified scope.

Release QA: **318 unit tests passed**, including the loopback HTTP fixture. Both build-6 install and launch cases and all six build-5 clone playbooks passed `copyapp verify`. Device evidence and signing assets remain in ignored local `cases/`; no phone IPA or private data is published. Wheel SHA-256: `04301af1fedf9f30b0c153d1620b2a2e0d2a74784f5c65c92a8b3bce7606aca1`.
