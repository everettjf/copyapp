# Development checkpoints

These v0.1.1–v0.1.17 notes document local build and device-validation checkpoints before the first public v0.1.0 milestone. Their version-like filenames and wheel hashes are historical evidence; the current repository has no matching Git tags or GitHub Releases for them. Some text uses the word “release” in its original chronology. Use [published releases](../releases/README.md) for installation and version selection.

The notes remain available so earlier experiment links and limitations can be inspected. Device cases and IPA snapshots referenced by them live in ignored local `cases/` and are not downloadable release assets.
