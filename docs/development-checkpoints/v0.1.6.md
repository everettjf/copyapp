# Copy APP v0.1.6: completed iOS 16 and 17 selected-flow validation

[English](v0.1.6.md) · [简体中文](v0.1.6.zh-CN.md)

Two connected, jailbroken phones were checked for this release: iPhone XR / iOS 16.1.1 / Dopamine rootless and iPhone 14 / iOS 17.3.1 / Relaxin RootHide. New `copyapp doctor` cases on both report available USB identity, screenshot, developer filesystem, pinned mobile SSH, Frida, iOS MCP and paired iCTRL. Their local evidence is `cases/ios16-v016-doctor-20261017/` and `cases/ios17-v016-doctor-20261017/`; both pass `copyapp verify`. This is a result for these exact devices and configurations.

The XR's previously completed [Calculator current-agent parent](../../cases/calculator-current-auto-workflow-20261016/manifest.json) and Clock parent were reverified. The Calculator parent covers three selected arithmetic flows with a source-linked report, independent installed clone, three passing paired final-view assertions and three image pairs reviewed as minor differences. The [v0.1.5 release record](v0.1.5.md) separately documents the known-source fixture's text-receiving share extension and Counter, Notes and Catalog regressions on both phones.

The iPhone 14 now has one completed [four-flow `copyapp copy` parent](../../cases/ios17-calculator-current-parent-20261017/manifest.json). It collected the installed Calculator 1.0.0 package and bounded sandbox index, then replayed four original portrait flows. Frida recorded one current-IMP and one original static-entry `CalculatorModel::buttonPressed:` hit in each selected tap window; bounded ARM64 disassembly shows an input dispatch, without recovering the entire arithmetic implementation. The current coding agent reviewed the draft, produced a [source-linked report and feature specification](../../cases/ios17-calculator-current-parent-20261017/analysis-agent/reviewed-report/report.md), then installed the previously authored, development-signed independent Calculator project. A fresh same-device comparison passed exact final UIKit results `15`, `0.3`, `−7` and `0.5` for all four flows. Five screenshot pairs were manually reviewed: all have minor result-font or system back-label differences and none has a major difference. The report, installation, comparison, visual review, delivery and parent all pass `copyapp verify`.

The iOS 17 clone source was written in the earlier [new-source pilot](../ios17-calculator-fresh-from-report.md), before this parent case. The parent confirms that `--agent-provider current` can resume across analysis and rebuild handoffs with that source; it does not show an Agent generating an unfamiliar App from one sentence. The `--no-decrypt --no-network` options bounded this Calculator run; the unencrypted system Calculator did not require FairPlay recovery. RootHide encrypted-package recovery is documented separately. Neither phone's cases establish whole-App equivalence, every UI state, every protection method, iOS 26 support, or a standalone Claude CLI run.

This release changes the package version and validation documentation; the CLI behavior and device packages are unchanged from v0.1.5. The 309-test Python suite passed. The wheel metadata and `copyapp` entry point were checked; `copyapp-0.1.6-py3-none-any.whl` SHA-256: `50c925916fb83a35c0265eeffbd14c3430dc1117f2f79284ee2c8b407ec9907f`.
