# Copy APP v0.1.12：双机独立采集命令打通

[English](v0.1.12.md) · [简体中文](v0.1.12.zh-CN.md)

独立的 `copyapp acquire --transport ssh` 和 `copyapp sandbox` 现在会按精确 `--udid`、固定主机密钥和所选账号，自行建立并认证短时 USB SSH 转发。此前两条命令需要另开转发，虽然 `analyze` 已能自行管理。若连接到另一台手机，身份检查仍会失败。

在 iPhone XR / iOS 16.1.1 Dopamine rootless 与 iPhone 14 / iOS 17.3.1 Relaxin RootHide 上，Apple Podcasts 完成包与静态分析、有界沙盒索引。通过校验的分析案例分别含 153/152 个包文件与 13/12 个二进制索引。两机主程序都没有加密加载命令，因此这次没有检验砸壳。独立采集案例也通过 `copyapp verify`；独立 `sandbox` 输出的是 JSON 索引，不是验证案例。

两机各自通过资料库、搜索、现在收听三条 `discover-check` 路径，六张末端截图已检查。iOS 17 第一次启动报错时，SpringBoard 实际显示 Podcasts 欢迎页；完成引导、无线数据选 WLAN Only 后，Podcasts 进入自身前台进程并通过三条脚本。XR 另有资料库介绍页。这些路径只验证进入 App 与导航；尚未完成 Podcasts 语义代码报告、独立复刻、播放或整 App 等价。[双机矩阵](../two-device-verification-matrix.zh-CN.md)。

发布验收：允许本地 HTTP 测试夹具绑定回环地址后，**314 项单元测试通过**；此前沙盒内尝试在夹具初始化时失败。Wheel 已从隔离目录加载为 **0.1.12**。Wheel SHA-256：`4d2e90a469fa819ff25f67570f1a8e30c4748a85cdfca00805cacb9110198841`。本地手机案例与私有 App 数据仍被 Git 忽略。
