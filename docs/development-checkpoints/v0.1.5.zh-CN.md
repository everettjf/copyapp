# Copy APP v0.1.5：iOS 16/17 分享扩展收到纯文本

[English](v0.1.5.md) · [简体中文](v0.1.5.zh-CN.md)

本版延续 [v0.1.4 双机分享扩展入口验收](v0.1.4.zh-CN.md)。测试设备仍是 iPhone XR / iOS 16.1.1 / Dopamine rootless 与 iPhone 14 / iOS 17.3.1 / Relaxin RootHide。此前的选定流程分析、加密包、Frida、独立复刻版与 SQLite 结果仍以各自记录的范围为准。

已知源码夹具升级为 0.1.2（build 3）。`FixtureShare.appex` 现在从系统 `NSItemProvider` 读取文本项并显示有界预览。两台手机的扩展都把主 App 分享的精确合成文本 `Copy APP fixture sample text` 显示为 `Received: Copy APP fixture sample text`。XR 12 步与 iPhone 14 14 步 iOS MCP 脚本通过，末端保存 UIKit 观察和截图；两台的安装案例均通过 `copyapp verify`。这个精确构建上的六条 Counter、Notes、Catalog 回归也通过。[双机记录](../fixture-share-extension-two-device.zh-CN.md)说明证据和保留的 XR 安装超时案例；停止主 App 与扩展进程后，同包重试成功。

本版 309 项 Python 测试通过。`copyapp-0.1.5-py3-none-any.whl` 的元数据与 CLI 入口已检查；wheel SHA-256：`d5213c1460cac24cb63afd51478f084f7b36c89644df19b6804ec08b872dbe12`。

结果证明指定两机上一个已知源码扩展的一条合成纯文本路径。其他内容类型、持久化、网络影响、其他扩展、整 App 等价、陌生 App 自主复刻、Claude CLI 独立全自动运行和 iOS 26 仍未验证。RootHide 上，固定版本 Frida 17.23.3 独立服务仍是原版 Calculator 的已验证跟踪路径；自带 16.1.4 服务在该 App 上仍失败。
