# Copy APP v0.1.13：内嵌 Framework 跟踪与双机 Podcasts 交付

[English](v0.1.13.md) · [简体中文](v0.1.13.zh-CN.md)

Frida 静态绑定现可处理内嵌 `.framework` 内的 Mach-O，并用相对所属 `.app` 的完整路径匹配已加载模块，同时保留主程序路径。该修复来自 `PodcastsStoreUI.SearchLandingCell` 跟踪；新增定向回归测试。XR 的搜索点击窗口记录该初始化方法当前 IMP 和静态偏移各 12 次命中。iOS 17 正确附加 Framework hook，但采样窗口命中零次，不能据此认定该类未使用。

Apple Podcasts 现已在 iPhone XR / iOS 16.1.1 / Dopamine rootless 与 iPhone 14 / iOS 17.3.1 / Relaxin RootHide 上分别完成有来源的审阅报告和分析交付。报告之后，当前 Agent 全新编写[独立 UIKit 工程](../../rebuild/PodcastsFreshProbe/README.md)，用 Xcode 27 构建，并分别经 TrollStore 和 Apple Development 签名路径安装。两机各通过 3/3 条原版／复刻版资料库、搜索和现在收听页面标题检查。六对截图全部审阅：XR 搜索页的插画及控件有重大差异；iOS 17 三对均有重大差异，包括缺少账号相关内容。两机可校验交付均如实标为 `selected_behavior_verified_visual_gap`。[详细证据与边界](../podcasts-two-device-report-rebuild.zh-CN.md)。

此版本验证两台指定配置上的选定分析、内嵌 Framework 跟踪、构建、安装及导航，不代表 Podcasts 全功能或视觉一致，也未证明陌生 App 零样本自主生成、独立 Claude CLI 运行或 iOS 26 支持。Podcasts 主程序未加密，因此本轮没有重新检验砸壳。发布物不包含手机私有案例、签名材料或 IPA。

发布验收：**315 项单元测试通过**，包括本地 HTTP 测试夹具。隔离安装的 wheel 加载为 **0.1.13**，CLI 入口可调用。Wheel SHA-256：`2475e591ccf9b9026ac87a9928daf7a5a048a16fb5995c52ee9624192f063590`。
