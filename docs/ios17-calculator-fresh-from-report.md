# iOS 17 Calculator: new source from a reviewed report

[English](ios17-calculator-fresh-from-report.md) · [简体中文](ios17-calculator-fresh-from-report.zh-CN.md)

The [iPhone 14 Calculator report](../cases/iphone14-calculator-frida17-deep-report-v3-20261017/report.md) selected one portrait flow, `7 + 8 = 15`, and tied its visible result, UIKit view tree, button dispatch and main-binary identity to verified evidence. Earlier iOS 17 delivery reused an existing clone. This run wrote a separate [UIKit project](../rebuild/CalculatorIOS17Fresh) under `dev.copyapp.calculator.ios17fresh` without reusing the earlier clone source. Its implementation follows the selected behavior and layout in that report; it does not recover the original Apple source or the private Calculate framework algorithm.

The project was built for iOS 17, development-signed, installed on the report's iPhone 14 / iOS 17.3.1, and checked through the iOS MCP backend. The local IPA SHA-256 is `d3ae127dbad0576b0552859a70a716b01528eda19fa83f81d388df73770b884b`. [Installation](../cases/ios17-calculator-fresh-install-20261017/install.json) and the initial [clone playbook](../cases/ios17-calculator-fresh-basic-ui-20261017/manifest.json) passed `copyapp verify`; the clone's final accessibility observation contains the exact text `15`.

For a formal paired check, the report's one-flow feature specification was copied locally with only `rebuilt_bundle_id` changed to the new Bundle ID. This is a declared derivative, not a claim that the original report targeted this new App. The [paired case](../cases/ios17-calculator-fresh-rebuild-check-20261017/report.md) replayed the same `all clear → 7 → add → 8 → equals` script on the original and the new App, saved two screenshot pairs, and passed its final UIKit text assertion on both. The [visual review](../cases/ios17-calculator-fresh-visual-review-20261017/report.md) judged both pairs as minor differences: the displayed number and keypad arrangement match, while the result font and system return-to-App label differ. Both cases passed `copyapp verify`.

This closes the specific **report → newly written source → signed App → same-device comparison** gap for one iOS 17 Calculator flow. Decimal entry, other operators, history, precision edge cases, landscape/scientific mode, accessibility variants and whole-App equivalence remain unverified. The source was authored with a prior screenshot and selected report available, so this is not unfamiliar-App zero-shot autonomy. Evidence paths under `cases/` are local and Git-ignored; the source project is tracked.
