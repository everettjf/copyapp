# iOS 17 Calculator: new source from a reviewed report

[English](ios17-calculator-fresh-from-report.md) · [简体中文](ios17-calculator-fresh-from-report.zh-CN.md)

The [iPhone 14 Calculator report](../cases/iphone14-calculator-frida17-deep-report-v3-20261017/report.md) selected one portrait flow, `7 + 8 = 15`, and tied its visible result, UIKit view tree, button dispatch and main-binary identity to verified evidence. Earlier iOS 17 delivery reused an existing clone. This run wrote a separate [UIKit project](../rebuild/CalculatorIOS17Fresh) under `dev.copyapp.calculator.ios17fresh` without reusing the earlier clone source. Its implementation follows the selected behavior and layout in that report; it does not recover the original Apple source or the private Calculate framework algorithm.

The project was built for iOS 17, development-signed, installed on the report's iPhone 14 / iOS 17.3.1, and checked through the iOS MCP backend. The first build passed a one-flow paired check. Three further original-App observations covered decimal addition, negative addition and percentage. They exposed a visible difference: the original displayed the Unicode minus `−7`, while the first clone displayed `-7`. The clone now uses the original's minus glyph and was reinstalled as version 0.1.1 (build 2). The revised local IPA SHA-256 is `a7d58fd85b3c8b78927dbd6153a33fe01d2d7b707203a05ac734bd2420fc1aab`; its [install case](../cases/ios17-calculator-fresh-v2-install-20261017/install.json) passed `copyapp verify`.

The tracked [four-flow specification](../rebuild/CalculatorIOS17Fresh/feature-spec.json) is explicitly derived from the report's one-flow specification: it selects a new rebuilt Bundle ID and adds three flows supported by current-device UI observations. Those added flows do not inherit the report's static or Frida claims. The [formal paired case](../cases/ios17-calculator-fresh-four-flow-check-20261017/report.md) replayed four original/clone scripts on the same phone. Final UIKit text assertions passed on both sides for `15`, `0.3`, `−7` and `0.5`. The [visual review](../cases/ios17-calculator-fresh-four-flow-visual-review-20261017/report.md) covered all five saved screenshot pairs and judged each a minor difference: the keypad arrangement and tested results match, while the result font and system return-to-App label differ. The paired and review cases passed `copyapp verify`.

This closes the specific **report → newly written source → signed App → same-device comparison** gap for the report's one flow and extends real-device comparison to three UI-observed flows. Other operators, history, precision edge cases, landscape/scientific mode, accessibility variants and whole-App equivalence remain unverified. The source was authored with a prior screenshot and selected report available, so this is not unfamiliar-App zero-shot autonomy. Evidence paths under `cases/` are local and Git-ignored; the source and playbooks are tracked.
