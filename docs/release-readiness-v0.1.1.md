The user deferred work on a second physical Mac for this round. Its USB pairing, first SSH authorization, UI control, package/sandbox acquisition and signed or TrollStore rebuild remain unverified against the original setup gate. iCTRL's rebuilt-App multi-step failure on iOS 17 also needs either a verified fix or a clear release limitation. Reboot/rejailbreak persistence is an untested durability boundary; either verify it or explicitly retain that limitation in the final notes. Before publishing, review `git diff v0.1.0..main`, run the suite on the final commit, finalize the bilingual notes, bump the package version once, tag once and publish one GitHub Release. A green verifier proves case consistency, not semantic correctness or whole-App equivalence.
