Copy APP شواهد مربوط به بستهٔ برنامه، رابط کاربری، محیط ایزوله و رفتار زمان اجرا را از برنامه‌ای نصب‌شده روی آیفون جیلبریک‌شده جمع‌آوری می‌کند. سپس گزارشی تحلیلی با ارجاع به منابع می‌سازد و برای پیاده‌سازی مستقل قابلیت‌های منتخب در یک برنامهٔ قابل اجرای iOS و مقایسهٔ آن روی دستگاه واقعی کمک می‌کند.

## سازوکار

یک عامل کدنویسی Copy APP CLI را روی مک اجرا می‌کند. OpenSSH، Frida، iOS MCP یا iCTRL اختیاری، شواهد را از آیفون مشخص‌شده می‌گیرند. در صورت نیاز، Ghidra یا Hopper کد بومی را روی مک بررسی می‌کنند. گزارش بازبینی‌شده و `feature-spec.json` پیاده‌سازی جدید را هدایت می‌کنند؛ سپس جریان‌های برنامهٔ اصلی و نسخهٔ جدید روی همان گوشی تکرار و تصویرها بررسی می‌شوند. [نمودار معماری و راهنمای کامل نصب](../../README.md#how-it-works) به انگلیسی در دسترس است.

## شروع سریع

Python 3.9 یا جدیدتر را روی مک نصب کنید، آیفون جیلبریک‌شده را با USB وصل کنید و اعتماد به رایانه را تأیید کنید؛ سپس اجرا کنید:

```sh
git clone https://github.com/everettjf/copyapp.git
cd copyapp
sh scripts/bootstrap-macos.sh
.venv/bin/copyapp onboard
```

ابتدا [بررسی اولیهٔ USB](../../README.md#install-and-run-your-first-survey) را انجام دهید. تحلیل عمیق به SSH، Frida و سرویس رابط کاربری روی گوشی نیز نیاز دارد.

## اصول و مشارکت

پیش از تفسیر، شواهد را ثبت کنید و موارد نامعلوم را روشن بگویید. تأیید چند جریان منتخب به معنای برابری کامل برنامه‌ها نیست. گزارش خطای بازتولیدپذیر، آزمون، اسکریپت رابط کاربری و ترجمه پذیرفته می‌شود. فایل IPA، اطلاعات ورود یا دادهٔ خام محیط ایزوله را در Git قرار ندهید. [راهنمای مشارکت](../../CONTRIBUTING.md) را ببینید.

iPhone XR با iOS 16.1.1 و جریان تحلیل و بازسازی منتخب روی iPhone 14 با iOS 17.3.1 (Relaxin/RootHide) آزمایش شده‌اند؛ iOS 26 هنوز آزمایش نشده است. برای جزئیات، [محدودهٔ پشتیبانی](../../README.md) را ببینید. زبان مستندات، زبان CLI یا گزارش‌ها را تغییر نمی‌دهد.
