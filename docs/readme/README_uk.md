# Copy APP

**Мова:** Українська · [Усі мови](../../README.md#languages) · [English](../../README.md)

Copy APP збирає докази про пакет, інтерфейс, пісочницю та поведінку встановленого застосунку на iPhone із джейлбрейком. Проєкт створює аналітичний звіт із посиланнями на джерела й допомагає реалізувати вибрані функції в незалежному робочому iOS-застосунку та порівняти їх на реальному пристрої.

## Як це працює

Агент програмування керує Copy APP CLI на Mac. OpenSSH, Frida, iOS MCP або необов'язковий iCTRL збирають дані саме з вибраного iPhone. За потреби Ghidra чи Hopper аналізують нативний код на Mac. Перевірений звіт і `feature-spec.json` спрямовують нову реалізацію; сценарії оригіналу й нової версії відтворюються на одному телефоні, а знімки екрана переглядаються. [Схема архітектури й докладне налаштування](../../README.md#how-it-works) доступні англійською.

## Швидкий початок

Установіть Python 3.9+ на Mac, під'єднайте iPhone із джейлбрейком через USB, підтвердьте довіру й виконайте:

```sh
git clone https://github.com/everettjf/copyapp.git
cd copyapp
sh scripts/bootstrap-macos.sh
.venv/bin/copyapp onboard
```

Спочатку пройдіть [первинне USB-обстеження](../../README.md#install-and-run-your-first-survey). Для глибокого аналізу додатково потрібні SSH, Frida та служба інтерфейсу на телефоні.

Вітаємо відтворювані звіти про помилки, тести, UI-сценарії та переклади. Не додавайте до Git IPA, облікові дані чи сирі дані пісочниці. Див. [посібник для учасників](../../CONTRIBUTING.md).
