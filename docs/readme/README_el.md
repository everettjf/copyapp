Το Copy APP συλλέγει τεκμήρια για το πακέτο, το περιβάλλον χρήστη, το sandbox και τη συμπεριφορά κατά την εκτέλεση μιας εφαρμογής εγκατεστημένης σε iPhone με jailbreak. Παράγει αναφορά ανάλυσης με παραπομπές στις πηγές και βοηθά στη δημιουργία ανεξάρτητης εφαρμογής iOS που αναπαράγει επιλεγμένες λειτουργίες για σύγκριση στην πραγματική συσκευή.

## Πώς λειτουργεί

Ένας agent προγραμματισμού χειρίζεται το Copy APP CLI στο Mac. Τα OpenSSH, Frida, iOS MCP ή το προαιρετικό iCTRL συλλέγουν τεκμήρια από το συγκεκριμένο iPhone. Αν χρειάζεται, τα Ghidra ή Hopper αναλύουν τον εγγενή κώδικα στο Mac. Η ελεγμένη αναφορά και το `feature-spec.json` καθοδηγούν τη νέα υλοποίηση· τα ίδια σενάρια εκτελούνται στην αρχική και στη νέα εφαρμογή, ενώ εξετάζονται και τα στιγμιότυπα οθόνης. Το [διάγραμμα αρχιτεκτονικής και ο πλήρης οδηγός εγκατάστασης](../../README.md#how-it-works) είναι στα αγγλικά.

## Γρήγορη εκκίνηση

Εγκαταστήστε Python 3.9+ στο Mac, συνδέστε μέσω USB ένα iPhone με jailbreak, επιβεβαιώστε την εμπιστοσύνη και εκτελέστε:

```sh
git clone https://github.com/everettjf/copyapp.git
cd copyapp
sh scripts/bootstrap-macos.sh
.venv/bin/copyapp onboard
```

Ξεκινήστε με την [αρχική εξέταση μέσω USB](../../README.md#install-and-run-your-first-survey). Για βαθύτερη ανάλυση χρειάζονται επίσης SSH, Frida και υπηρεσία χειρισμού διεπαφής στο τηλέφωνο.

## Αρχές και συνεισφορά

Καταγράφετε πρώτα τα τεκμήρια και μετά τα ερμηνεύετε, δηλώνοντας ρητά τα άγνωστα. Η επιτυχία επιλεγμένων σεναρίων δεν αποδεικνύει πλήρη ισοδυναμία εφαρμογών. Δεκτές είναι οι αναπαραγώγιμες αναφορές σφαλμάτων, οι δοκιμές, τα σενάρια UI και οι μεταφράσεις. Μην υποβάλλετε IPA, διαπιστευτήρια ή ακατέργαστα δεδομένα sandbox στο Git. Δείτε τον [οδηγό συνεισφοράς](../../CONTRIBUTING.md).

Έχουν επαληθευτεί επιλεγμένες ροές στο iPhone XR με iOS 16.1.1, στο iPhone 14 με iOS 17.3.1 και για τα Calculator και Clock στο iPhone 11 με iOS 26.0.1. Δείτε το [εύρος υποστήριξης](../../README.md). Η γλώσσα της τεκμηρίωσης δεν αλλάζει τη γλώσσα του CLI ή των αναφορών.
