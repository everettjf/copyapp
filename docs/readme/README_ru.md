Copy APP собирает сведения о пакете, интерфейсе, песочнице и поведении установленного приложения на iPhone с джейлбрейком. На их основе создаётся аналитический отчёт со ссылками на источники, а выбранные функции реализуются в отдельном работающем iOS-приложении и сравниваются на настоящем устройстве.

## Как это работает

Кодовый агент управляет Copy APP CLI на Mac. OpenSSH, Frida, iOS MCP или необязательный iCTRL собирают данные с указанного iPhone. При необходимости Ghidra или Hopper анализируют нативный код на Mac. Проверенный отчёт и `feature-spec.json` направляют реализацию; сценарии исходного и нового приложения запускаются на одном телефоне, а снимки экрана сравниваются. [Схема архитектуры и подробная установка](../../README.md#how-it-works) доступны на английском.

## Быстрый старт

Установите Python 3.9+ на Mac, подключите iPhone с джейлбрейком по USB, подтвердите доверие и выполните:

```sh
git clone https://github.com/everettjf/copyapp.git
cd copyapp
sh scripts/bootstrap-macos.sh
.venv/bin/copyapp onboard
```

Сначала пройдите [первичное USB-обследование](../../README.md#install-and-run-your-first-survey). Для глубокого анализа нужны SSH, Frida и сервис управления интерфейсом на телефоне.

## Принципы и участие

Сначала сохраняйте доказательства, затем делайте выводы; неизвестное обозначайте явно. Проверка выбранных сценариев не доказывает полную эквивалентность приложения. Приветствуются воспроизводимые ошибки, тесты, UI-сценарии и переводы. Не отправляйте IPA, учётные данные и исходные данные песочницы. См. [руководство для участников](../../CONTRIBUTING.md).

Проверен iPhone XR с iOS 16.1.1. iOS 17 и 26 пока не тестировались. Язык документации не меняет язык CLI или отчётов.
