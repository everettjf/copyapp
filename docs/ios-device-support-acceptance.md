## Formal credential entry and installed-wheel isolation

The subsequent [`credential-retrieve` command](ios-fairplay-credentials.md) replaces the ad hoc adapter for normal use. It checks 33 public source inputs, builds/signs fresh native helpers, binds USB/SSH/native identity, selects an explicit installed App, optionally checks a verified IPA's account and SINF, and saves a new private alias only after SINF validation and remote cleanup. Existing aliases are not overwritten. New `ios_fairplay_credential` cases dispatch explicitly in `copyapp verify`; historical cases retain their validators. Saved verification does not read or hash the private credential.

The [formal live run](../output/fairplay-credential-ios17-20261023/formal-retrieval/report.md) passed all stages on the same iPhone 14 / iOS 17.3.1 and also validated the selected Remoboard IPA. The [full suite](../output/fairplay-credential-ios17-20261023/full-unit-tests.log) passed **495 tests in 62.028 seconds**, including 16 new tests for exact identity, account mismatch, changed source, secret-store collision, invalid credential, interrupted observation, cleanup failure, rehashed record/source tampering and wheel SSH defaults. The [installed wheel check](../output/fairplay-credential-ios17-20261023/installed-wheel-check.json) ran outside the checkout: **125 source resources matched; 50 expected case outcomes matched**. The wheel SHA-256 is `4cfc578fb2ef0a5ae72872752e5ada569f684cb1545548c284456c2bf79c5c93`. A [separate fresh-venv install](../output/fairplay-credential-ios17-20261023/fresh-wheel-check.log) also passed.

Using the formal alias, the installed wheel then recovered Remoboard's encrypted main and keyboard extension inside macOS `sandbox-exec` with `(deny network*)`. [The probes](../output/fairplay-credential-ios17-20261023/isolated-offline-check.json) observed denied USBMux socket access, denied device enumeration and denied localhost connectivity. The [offline case](../output/fairplay-credential-ios17-20261023/remoboard-isolated-offline/report.md) and [cross-check](../output/fairplay-credential-ios17-20261023/remoboard-isolated-cross-check/report.md) both verify and match the independent device recovery. Both phones were still physically connected during that first isolation run.

The user then physically unplugged both phones. [Fresh inventories](../output/fairplay-credential-ios17-20261023/disconnected-offline-check.json) observed **zero devices before and after** a separate installed-wheel [offline run](../output/fairplay-credential-ios17-20261023/remoboard-disconnected-offline/report.md) and [cross-check](../output/fairplay-credential-ios17-20261023/remoboard-disconnected-cross-check/report.md), additionally protected by the same network-denial sandbox. Both complete recovered programs match the independent device recovery; their package and cross-check cases verify. This closes the physical-disconnection TODO. No iPhone 11 jailbreak activation or phone restart was performed. The PR stays draft and unmerged.

The [final installed-wheel audit](../output/fairplay-credential-ios17-20261023/final-validation.json), expanded with those four additional recovery/comparison cases, matches **all 54 expected case outcomes**, checks private credentials are absent from changed files, and resolves the local Markdown links in the changed documentation without missing targets. Credential values are compared only in memory and are never included in that audit.

The published support list must remain narrower than this design until the open gates have actual evidence. No arbitrary-App copy, arbitrary-phone support, private sandbox access on ordinary phones, native function semantics or backend parity follows from these named results.
