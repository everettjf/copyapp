## Authenticated download and three-route follow-up

- **Inactive jailbreak / iPhone 11, iOS 26.0.1:** free FocusTodo (`com.s.kawano.focusTodo`) 1.0.4 (4), external version `893656071`, downloaded through authenticated ipatool 2.7.0. [Package](../output/ios-device-support-20261023-7f2a/focustodo-store-download/report.md), [reviewed UI report](../output/ios-device-support-20261023-7f2a/focustodo-reviewed-report/report.md) and [analysis delivery](../output/ios-device-support-20261023-7f2a/focustodo-analysis-delivery/report.md) verify. Two fresh-launch flows create a test card, retain it after cold launch and right-swipe it away. All three full flow screenshots were opened. Main, App/Flutter frameworks and Widget remain encrypted; no FocusTodo rebuild or plaintext recovery is claimed. Storefront is not independently verified. USB InstallationProxy completed registration with Apple's App Store signer, but the development-signature install command correctly retained a failed profile check; later UI success does not rewrite that case or certify the development-install contract.
- **Enhanced / iPhone 14 (`iPhone14,7`), iOS 17.3.1 (`21D61`):** the [fresh parent](../output/ios-device-support-20261023-7f2a/ios17-enhanced-fixture-analysis/TASK.md) collected the owned fixture package and sandbox metadata over SSH and asserted a note-count increment. Its [separate investigation](../output/ios-device-support-20261023-7f2a/ios17-enhanced-fixture-investigation/review-brief.md) observes 8→9 notes and one `FixtureNotesViewController::addNote` hit at both the current IMP and original entry during Add. Both full images were opened. Bounded assembly follows a local Swift entry; this is not a completed deep interpretation. A [post-fix enhanced run](../output/ios-device-support-20261023-7f2a/ios17-root-aware-enhanced-analysis/TASK.md) confirms collection remains available without root.
- **Root privilege separation:** that phone's full-access Frida route actually spawns UID `501`. New capability model 2 independently [probes a suspended child](../output/ios-device-support-20261023-7f2a/ios17-root-aware-onboard/root-spawn.json), stops it without resuming its executable, and keeps trace/analysis/sandbox available while [device decryption is unavailable](../output/ios-device-support-20261023-7f2a/ios17-root-aware-onboard/report.md). An [explicit `--decrypt` negative](../output/ios-device-support-20261023-7f2a/ios17-root-required-decryption-negative/TASK.md) stops before App collection or UI replay. Root SSH and noninteractive sudo are also unavailable; no authentication or privilege setting was changed. Earlier model-1 plans retain their historical readiness fields and must not be read as verified root capability. A matching credential and independent positive recovery remain open.
- **Second named standard-mode combination:** the same iOS 17 phone passed [explicit standard analysis](../output/ios-device-support-20261023-7f2a/ios17-explicit-standard-analysis/TASK.md), using signed XCTest, exact USB screenshots and a note-count assertion. That run skipped SSH/Frida/MCP; existing RootHide services were not disabled. It is another named system/route regression, not pristine ordinary-device acceptance. The iPhone 11's [post-fix standard probe](../output/ios-device-support-20261023-7f2a/ios26-root-aware-standard-onboard/report.md) likewise skips all root/jailbreak probes.
- **macOS regression:** the existing independent editor in the macOS 27.0.1 (`26A434`) ChatComputer 0.9.11 VM passed [17 steps / eight assertions](../output/ios-device-support-20261023-7f2a/mac-editor-wrap-regression/manifest.json): Tools menu, wrapping shortcut, normal exit/relaunch preference retention, Reset and final exit. [All 20 full images were opened](../output/ios-device-support-20261023-7f2a/mac-regression-image-review.json). Collector timeouts after host reboot were retained; a normal guest restart and existing verified launcher restored a fresh exact environment. This is an existing-build regression, not another reconstruction, paired delivery or physical-Mac test.

The final root-readiness implementation passed **471 tests in 52.557 seconds**; see the [test log](../output/ios-device-support-20261023-7f2a/unit-tests-root-readiness-final.log). The tests cover refusing missing root, accepting a later repaired route without rewriting its original baseline, and verifying that resumed evidence. [Case verification](../output/ios-device-support-20261023-7f2a/three-route-case-verification.json) matches all 36 expected results, including retained failures and deliberate tampering. The [installed wheel check](../output/ios-device-support-20261023-7f2a/root-readiness-installed-wheel-check.json) ran outside the checkout, matched all 123 Python/Swift/Java resources to source and revalidated the same 36 new/historical iOS and Mac results. Its SHA-256 is `e2bfaeffacdcc761113aa95080ecf462d7ef77acc6318cd282ae69695c1604c5`. This is a local development wheel, not a release.

The published support list must remain narrower than this design until the open gates have actual evidence. No arbitrary-App copy, arbitrary-phone support, private sandbox access on ordinary phones, native function semantics or backend parity follows from these named results.
