# Copy APP v0.1.2

[English](v0.1.2.md) · 简体中文

本次小版本修复 iOS 17 成对重放中的 iCTRL XCTest 会话生命周期故障，并把交给 Coding Agent 的首次使用入口放到 README 最前面。

## 本版改动

- 在全部选定原版／复刻版流程及即时 view-tree 采集期间保持同一个自建 iCTRL 会话。退出时先停止所拥有的 runner，再断开 XCTest 宿主，避免下一次命令复用仍能短暂响应的残留会话。
- 会话清理失败时保留失败状态。HTTP 响应丢失时明确提示执行结果未知，要求先检查日志和 UI；不会自动重发触摸。
- 新增仓库内 `copyapp-start` Skill，以及中英文 README 中可直接交给 Codex／Claude Code 的提示词。Agent 可检出项目、检查 Mac 环境、识别准确设备与 App，再进入所需的采集、分析或复刻流程。手动 CLI 入口继续保留。

## 验证与边界

指定 iPhone 14／iOS 17.3.1／Relaxin RootHide 上，两轮独立正式命令每轮均通过四条原版／复刻版 Calculator 流程，末端结果为 `15`、`0.3`、`−7`、`0.5`，合计 88 条带标签点击命令。每轮退出后 runner PID 均为 0。十对截图已逐张审阅，字体、位置和符号字形的轻微差异仍保留记录。原始失败与受控实验留在忽略的本地案例中。

本版通过 **346 项本地单元测试**及隔离 wheel 构建／安装检查；打包检查要求包含新的 runner-stop 模块。上述真机结果来自本次修复已保存的复验记录，本轮发布打包没有重跑全部手机流程。

本次修改的清理逻辑**尚未在指定 iOS 16 和 iOS 26 手机上复验**。重启／重新越狱后的持续可用性、长时间稳定性、第二台实体 Mac 首次配置和陌生 App 自主探索仍待验证。历史指定设备结果与 iOS 26 黑帧恢复边界见[当前状态](../current-status.zh-CN.md)。选定流程通过不能证明整 App 或服务端行为等价。

## 使用

将 [README 中的任务](../../README.zh-CN.md#从这里开始)交给 Mac 本地运行的 Codex 或 Claude Code；也可检出此标签，运行 `sh scripts/bootstrap-macos.sh`。手机信任、首次授权和签名条件可能需要用户参与。

附件 `copyapp-0.1.2-py3-none-any.whl` 安装 Mac CLI，`SHA256SUMS` 记录校验和。仓库 Skill 和可选源码构建工具仍需保留源码检出。wheel 不包含手机 tweak、Theos、签名材料、设备证据或凭据。[v0.1.1 发布说明](v0.1.1.zh-CN.md)保留原始记录。
