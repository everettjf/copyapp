# Copy APP v0.1.11: retained TrollStore timeout evidence

[English](v0.1.11.md) · [简体中文](v0.1.11.zh-CN.md)

The XR TrollStore helper previously timed out on two identical-build reinstalls and one versioned Clock upgrade. A helper timeout no longer discards its bounded root-command log: `device-run/output.txt` and `device-run/result.json` record the output, elapsed-time failure, and whether stopping the Frida-spawned process was requested. `install.json` also records the installed Bundle ID's version/build returned by InstallationProxy after the timeout, or the probe error. The installer does not automatically retry an uncertain operation or claim that a stop request ended every child process. Existing failed cases remain failed.

A harmless one-second XR root command printed `timeout-control` and then slept. The real-device timeout case `cases/ios16-root-timeout-diagnostic-retry-v0111-20261017/` retained that output and recorded `status=timed_out`, `exit_code=null`, and `process_stop_requested=true`. An earlier attempt using `/bin/sh` exited 127 because the rootless shell is at `/var/jb/bin/sh`; it is retained separately. Unit tests cover the bounded timeout log and an installer timeout that observes the previous installed version without retrying.

The independent Clock project was versioned to **0.1.4 (5)** without changing its Stopwatch implementation. Its XR ad hoc IPA SHA-256 is `cd403edd08534c1c4049f8320af4bfbc526d7f7c317e92cffee1b12704410ee5`; its iPhone 14 development-signed IPA is `872a603dc411afe72c4b5a4f52619622f8afed76fdf3c54feff49086671ec7b4`. The XR TrollStore and iOS 17 signed USB upgrades both passed on their first attempt. Their install and stopped-relaunch cases each pass `copyapp verify`, and the exact pre-upgrade stopped values survived: XR `02:52.80`, iPhone 14 `02:00.94`. These two successes do not establish a first-attempt reliability rate or resolve the earlier intermittent helper hang.

Release QA: **314 unit tests passed**. The iOS MCP test suite binds a local HTTP server, so it was run with loopback access after a sandbox-only attempt failed at server setup. The packaged wheel was installed and its version and CLI entry tested in an isolated directory. Wheel SHA-256: `d4f4aba8b1a5b9db0f076c963013bf275c48f1b2676e88244bde95460c7c117b`. Local `cases/` evidence remains Git-ignored; [the two-device matrix](../two-device-verification-matrix.md) and [Clock record](../clock-clone-two-device.md) state the tested scope and open gates.
