# Copy APP v0.1.7: cross-device UI checks and Hopper verification fix

[English](v0.1.7.md) · [简体中文](v0.1.7.zh-CN.md)

This patch release fixes a real provider verification failure found while running `copy --analysis-provider hopper-direct` on the iPhone 14 / iOS 17.3.1. The analysis and Hopper decompilation completed, but `app_preparation` verification rejected the supported provider value `hopper-direct`, leaving the parent at `preparation_incomplete`. The verifier now accepts that value, with a regression test. Resuming the **same** saved parent reused its completed phone investigation and produced a reviewed report, installed the existing independent Calculator App, passed the selected `15` final-view assertion and reviewed two screenshot pairs as minor differences. The [parent and delivery](../../cases/ios17-hopper-current-parent-20261017/manifest.json) pass `copyapp verify`. Its clone source existed before this run.

The [two-device verification matrix](../two-device-verification-matrix.md) adds two committed, synthetic playbooks replayed on iPhone XR / iOS 16.1.1 and iPhone 14 / iOS 17.3.1 through **both** iOS MCP and iCTRL. Calculator's portrait left swipe visibly changed `98 → 9` in all four combinations, with before/after screenshots and final UIKit text. Safari's address field visibly received the exact synthetic `copyapp-fixture-hello` string in all four combinations; no search was submitted. Eight flow-capture cases pass `copyapp verify`. The Safari result narrows an older XR finding: iOS MCP text input failed in Translate's field, but works in Safari on the same XR. Translate's failure remains unresolved and App-specific.

A separate [direct Hopper queue](../../cases/ios17-calculator-hopper-queue-20261017/manifest.json) and [supplemental report](../../cases/ios17-calculator-hopper-supplement-20261017/report/report.md) also bind the traced Calculator `buttonPressed:` entry to bounded pseudocode. That output interprets an input dispatch; it is not original Apple source or a recovery of the private arithmetic algorithm.

The earlier [v0.1.6 release](v0.1.6.md) remains the baseline for fresh two-device capability checks and the four-flow iOS 17 Calculator workflow. This release still does not establish whole-App equivalence, unfamiliar-App zero-shot generation, a standalone Claude CLI run or iOS 26 support.

Release QA: **310 unit tests passed**. The `copyapp-0.1.7-py3-none-any.whl` metadata and `copyapp` console entry point were checked; SHA-256: `495acce37060afa9083ad4f3e60911f61d5c078e93fd6db83d5c425f72263388`.
