# Copy APP v0.1.9：同一 Clock 复刻项目实测 iOS 16 与 17

[English](v0.1.9.md) · [简体中文](v0.1.9.zh-CN.md)

[Clock 跨设备记录](../clock-clone-two-device.zh-CN.md)验证了同一个独立 UIKit 项目在 iPhone XR / iOS 16.1.1 / Dopamine rootless 和 iPhone 14 / iOS 17.3.1 / Relaxin RootHide 上的选定行为。XR 先前安装程序的可执行文件与当前项目构建一致；该构建的开发者签名副本通过 USB 安装到 iPhone 14，安装案例通过校验。两机上的原版 Clock 与复刻版均经 iOS MCP 完成相同的秒表启动、停止脚本，成对对照证据通过校验；复刻版还分别经 iCTRL 跑通该脚本。停止画面的左右并排截图已人工查看。

这只证明选定流程兼容，不代表整 App 等价。复刻版重新启动后会丢失秒表状态；自动化延迟造成计时值不同，标签文案、控件和系统返回文字也有可见差异。后台计时、闹钟、通知、Clock 全部页面和其他设备不在本次发布结论内。iOS 17 原版的一次前台竞争失败，以及尝试在复刻版点 Reset 的失败，均保留为本地失败案例；最终对照脚本没有悄悄重放动作。

发布验收：允许本机回环服务后，**310 项单元测试通过**。六份最终 UI 采集案例、两份成对对照案例和 iOS 17 复刻版安装案例通过 `copyapp verify`。在隔离目录安装后，核对了 `copyapp-0.1.9-py3-none-any.whl` 的版本与 CLI 入口。Wheel SHA-256：`923843ef602466b4660a4969b5c57f2901b8d6528f58053f17f9dfcc20795e1e`。本地 `cases/` 证据不提交 Git；脚本与本文档会提交。
