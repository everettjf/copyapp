# Copy APP v0.1.9: one Clock clone on iOS 16 and 17

[English](v0.1.9.md) · [简体中文](v0.1.9.zh-CN.md)

The [cross-device Clock record](../clock-clone-two-device.md) tests the same independent UIKit project on iPhone XR / iOS 16.1.1 / Dopamine rootless and iPhone 14 / iOS 17.3.1 / Relaxin RootHide. The XR's previously installed executable matches the current project build. A development-signed copy of that build was installed through USB on the iPhone 14 and its install case verified. On each phone the original Clock and clone passed the same selected Stopwatch start/stop script through iOS MCP, and their paired comparison case passed evidence verification. The clone also passed that script through iCTRL on each phone. The side-by-side stopped screens were manually inspected.

This is selected-flow compatibility, not whole-App equivalence. The clone currently loses Stopwatch state on fresh launch, unlike the original. Timer values differ with automation latency; tab wording, controls and system return labels have visible differences. Background timing, alarms, notifications, all Clock pages and other devices are outside this release claim. An iOS 17 original-App foreground race and a failed attempt to use Reset on the clone are retained as failed local cases; the final comparison scripts did not silently replay an action.

Release QA: **310 unit tests passed** with local loopback access. Six final UI capture cases, two paired comparison cases and the iOS 17 clone install case passed `copyapp verify`. The `copyapp-0.1.9-py3-none-any.whl` version and console entry were loaded from an isolated install directory. Wheel SHA-256: `923843ef602466b4660a4969b5c57f2901b8d6528f58053f17f9dfcc20795e1e`. Local `cases/` evidence is Git-ignored; the playbooks and this record are committed.
