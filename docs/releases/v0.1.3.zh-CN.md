# Copy APP v0.1.3：iOS 17 Calculator 新源码真机验收

[English](v0.1.3.md) · [简体中文](v0.1.3.zh-CN.md)

本版延续 [v0.1.2 双机验收](v0.1.2.zh-CN.md)。已验证范围是 iPhone XR / iOS 16.1.1 / Dopamine rootless 和 iPhone 14 / iOS 17.3.1 / Relaxin RootHide 上的选定流程分析与复刻。iOS 16/17 夹具对照、当前 SQLite 行内容检查、加密包试验和设备配置仍见此前发布记录。

## 本版新增

[iOS 17 Calculator 试验](../ios17-calculator-fresh-from-report.zh-CN.md)现在包含独立编写的 [UIKit 工程](../../rebuild/CalculatorIOS17Fresh/README.md)。其中 `7 + 8 = 15` 流程来自已审阅的 Calculator 深度报告；小数加法、负数加法和百分比三条流程来自同一台手机的当前界面观察，不继承深度报告中的静态或 Frida 结论。

该工程已在 iPhone 14 上构建、开发签名、安装和对照。初版负数显示 `-7`，原版显示 `−7`；0.1.1（build 2）已修复。正式四流程对照中，原版和新工程的末端 UIKit 文本断言分别通过 `15`、`0.3`、`−7`、`0.5`。五组截图逐张审阅均为轻微差异，主要是结果字体粗细及系统返回应用名称。版本库收录选定流程规格和原版／复刻版脚本，可重跑这些检查。已签名 IPA、截图及原始设备证据保留在本机被 Git 忽略的 `cases/`；公开发布包含源码、脚本和审阅记录。

## 验证与边界

本版的 309 项 Python 测试通过。本版更改示例 UIKit 源码、脚本、文档及包版本；新源码构建、安装、四流程真机对照和截图审阅通过对应检查。`copyapp-0.1.3-py3-none-any.whl` 的元数据及 CLI 入口已检查；wheel SHA-256：`2b023231f956c22c8fef40dd72540c8940ab4d6b1dec27f67c26a63e1c65a2f9`。

结论只覆盖指定设备与流程，不代表 Calculator 全 App 等价、陌生 App 的可靠自主复刻、Claude CLI 全自动实测、分享扩展用户入口实测或 iOS 26 支持。RootHide 自带 Frida 16.1.4 在原版 Calculator 上仍失败，固定版本 17.23.3 独立服务是已验证的跟踪路径。RootHide 加密包恢复使用 mobile SSH，因为当前 Frida 进程无法提供 root `root-run`。
