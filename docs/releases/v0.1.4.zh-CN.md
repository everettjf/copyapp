# Copy APP v0.1.4：iOS 16/17 分享扩展用户入口验收

[English](v0.1.4.md) · [简体中文](v0.1.4.zh-CN.md)

本版延续同一台 iPhone XR / iOS 16.1.1 / Dopamine rootless 与 iPhone 14 / iOS 17.3.1 / Relaxin RootHide 的 [v0.1.3 验收](v0.1.3.zh-CN.md)。此前的选定流程分析、加密包、Frida、独立复刻版和 SQLite 检查仍以各自记录的范围为准。

已知源码夹具新增 **Share sample text** 按钮，版本升级为 0.1.1（build 2）。两台手机的系统文本分享页都列出包内 `FixtureShare.appex` 对应的夹具分享目标，选择后显示扩展自己的居中文字。[双机记录](../fixture-share-extension-two-device.zh-CN.md)包含 XR 12 步与 iPhone 14 14 步 iOS MCP 重放、已校验的安装案例与截图，也保留首次安装超时及动态分享页坐标造成的失败案例。纳入版本库的脚本可在对应设备上重放。更新后，原版夹具的 Counter、Notes、Catalog 又分别在两台手机上运行，六个回归案例均通过 `copyapp verify`。

本版的 309 项 Python 测试通过。`copyapp-0.1.4-py3-none-any.whl` 的元数据与 CLI 入口已检查；wheel SHA-256：`7ae6b9260a3d66ecae84c7dbb0ecd5da5dd4b9edc0e80006c5c0c40dd0cf9dea`。

本次证明指定两机上的一个已知源码扩展可从用户分享入口打开并显示页面。该扩展本身不处理分享内容。第三方扩展的通用行为、整 App 等价、陌生 App 自主复刻、Claude CLI 独立全自动运行和 iOS 26 仍未验证。RootHide 上，固定版本 Frida 17.23.3 独立服务仍是原版 Calculator 的已验证跟踪路径；自带的 16.1.4 服务在该 App 上仍失败。
