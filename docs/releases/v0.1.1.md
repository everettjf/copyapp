# Copy APP v0.1.1

[English](v0.1.1.md) · [简体中文](v0.1.1.zh-CN.md)

This patch release gathers the work completed after v0.1.0 into one tested milestone. Copy APP still has two deliverables: a reviewed, source-linked analysis report for an installed App on a jailbroken iPhone, and an independent runnable iOS App that reproduces **selected, measured behavior**. The observed flows do not establish whole-App equivalence.

## Included work

- Rechecked the selected Analyze → Rebuild workflow on iPhone XR / iOS 16.1.1 (Dopamine rootless), iPhone 14 / iOS 17.3.1 (Relaxin/RootHide), and iPhone 11 / iOS 26.0.1 (Relaxin/RootHide). The [current validation record](../current-status.md) names the checks and their limits.
- Added ordered Mac/phone onboarding, exact-device SSH profiles, a fresh macOS bootstrap check, and an isolated wheel installation check. The Mac CLI wheel does **not** include a prebuilt phone tweak, Theos, signing assets, or credentials.
- Consolidated the setup, workflow, coverage and architecture guides; moved sample independent projects into `examples/rebuild/`; and added light-green diagrams and selected public evidence illustrations.
- Declared Apache-2.0 for project-owned code and documentation in package metadata and the repository license. Vendored iOS MCP, iCTRL and retained REA material keep their own notices.

## Named-device results and limits

| Device | Selected results | Open limit |
| --- | --- | --- |
| iPhone XR · iOS 16.1.1 | SSH-backed package/sandbox acquisition, Frida, iOS MCP and iCTRL; selected Notes, Calculator, Translate and Clock analysis/rebuild paths; recent aligned Counter pair passed. | Optional developer file listing can return `ConnectionTerminatedError`; SSH acquisition works. |
| iPhone 14 · iOS 17.3.1 | Current-code Calculator acquisition, four original/rebuilt iOS MCP arithmetic assertions, five screenshot pairs with minor differences, and selected original-App Frida button tracing. | An additional rebuilt-App iCTRL multi-step replay failed twice at equals with `malformed HTTP response`; repeatability is not established. |
| iPhone 11 · iOS 26.0.1 | USB/SSH acquisition, iCTRL and iOS MCP UI, Frida attach, reviewed Calculator and Clock reports, signed independent apps, and selected arithmetic/Stopwatch pairs. | iOS MCP may capture a black App area after a fresh Instruments launch; bounded recovery passed observed cases, but long-term reliability is unknown. |

Reboot/rejailbreak durability, first phone onboarding on a second physical Mac, unfamiliar-App autonomous discovery, server-side behavior, and complete visual or functional parity remain unverified. Some examples adapt existing source; their results are not evidence of generating a new App from scratch. See the [current-status page](../current-status.md) for the exact boundary of each claim.

The release candidate passed **342 local unit tests** and an isolated wheel build/install check. Device results above come from the saved named-device validation record; this packaging pass did not repeat every phone flow.

## Install

Clone this tag and run `sh scripts/bootstrap-macos.sh`, then follow the [first survey](../../README.md#start-here) and [full setup guide](../setup.md). The attached `copyapp-0.1.1-py3-none-any.whl` installs the Mac CLI. Configure the compatible phone services and build/signing route separately. Keep raw IPAs, sandbox data, complete screenshots and keys in ignored local `cases/`; they are not release assets.
