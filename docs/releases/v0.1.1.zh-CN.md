# Copy APP v0.1.1：iOS 16 与 17 真机验收

[English](v0.1.1.md) · [简体中文](v0.1.1.zh-CN.md)

此修订版延续 [v0.1.0 双机记录](v0.1.0.zh-CN.md)。克隆后执行 `git checkout v0.1.1`，再按 [Mac 安装步骤](../../README.zh-CN.md#新用户安装与第一次运行)配置。Python wheel 为 `copyapp-0.1.1-py3-none-any.whl`；手机端软件包和签名工具需另外安装。

| 验收项 | iPhone XR · iOS 16.1.1 · Dopamine rootless | iPhone 14 · iOS 17.3.1 · Relaxin/RootHide |
| --- | --- | --- |
| 设备通道 | 精确 USB、截图、DVT、mobile SSH、Frida、iOS MCP 和 iCTRL 均通过诊断 | 同样的通道通过诊断；Frida 使用固定版本 17.23.3 独立服务 |
| App 采集 | 新版夹具、Framework、分享扩展和沙盒索引通过校验；此前 DeepSeek 加密整包恢复案例再次校验 | 夹具组件通过校验；此前 Remoboard 主程序和键盘扩展恢复案例再次校验 |
| 安装 | 一条 `copyapp install` 命令自动建立精确设备 USB SSH 转发、安装新版夹具，安装案例通过校验 | Apple Development 签名的原版与独立复刻版经 USB 安装，安装案例通过校验 |
| 界面与复刻 | 原版/复刻版 Counter、Notes、Catalog 经 iCTRL 正式成对验收和五组截图审阅；更新后的原版又经 iOS MCP 跑通三条流程 | 原版三条流程经 iOS MCP 与 iCTRL；复刻版经 iOS MCP，正式成对验收和五组截图审阅通过 |

新增 XR 案例为 `ios16-fixture-self-tunnel-install-20261017` 和 `ios16-fixture-ios-mcp-{counter,notes,catalog}-20261017`，均通过 `copyapp verify`。iOS 17 对应案例与原正式成对验收见 [v0.1.0 记录](v0.1.0.zh-CN.md)。原始案例、IPA、截图和设备凭据保存在 Git 忽略的本地 `cases/`，不会公开。

`copyapp install` 现在会为精确 `--udid` 创建或复用临时 USB SSH 转发，通过固定的主机密钥校验设备身份，并在结束后关闭自己创建的转发。双机同时连接时仍需各自的 SSH 主机密钥文件和本地端口；TrollStore 直接安装不再要求事先手动开转发。

发布检查：309 项本地单元测试通过；v0.1.1 wheel 的元数据和命令行入口已检查。本地 wheel 的 SHA-256 为 `e5af46b9385a6fa1596c16c65a870bceb814a043c4a8904c5af8ade46e232336`。

这里的支持指两台指定设备通过了上述**选定流程**。夹具覆盖 SwiftUI/UserDefaults、UIKit/SQLite、Framework 和已打包的分享扩展；本次没有触发扩展的用户交互，也没有逐条核对 SQLite 行内容。Calculator 与加密第三方 App 提供不同技术栈的证据，但尚未证明陌生 App 的零样本自动复刻或整 App 等价。iOS 26 尚未测试。RootHide 的已验证加密包恢复路径使用 mobile SSH；该设备原有 Frida 16.1.4 与 root `root-run` 路径仍不可用，详见 [iPhone 14 记录](../relaxin-roothide-iphone14.md)。
