# Copy APP v0.1.1

[English](v0.1.1.md) · 简体中文

这个小版本把 v0.1.0 之后完成的工作集中为一次经过验证的发布。Copy APP 仍交付两项成果：越狱 iPhone 上已安装 App 的审阅版、带来源分析报告，以及复现**选定且已测行为**的独立可运行 iOS App。已通过的流程不代表整 App 等价。

## 本版内容

- 在 iPhone XR / iOS 16.1.1（Dopamine rootless）、iPhone 14 / iOS 17.3.1（Relaxin/RootHide）和 iPhone 11 / iOS 26.0.1（Relaxin/RootHide）复核选定的“分析 → 复刻”路径。[当前真机记录](../current-status.zh-CN.md)列明具体检查和限制。
- 加入按顺序执行的 Mac/手机配置、精确设备的 SSH 配置记录、全新 macOS 安装检查，以及隔离 wheel 安装检查。Mac CLI wheel **不包含**预编译手机 tweak、Theos、签名材料或凭据。
- 整理安装、工作流、覆盖目标和架构文档；把独立工程示例集中到 `examples/rebuild/`；加入浅绿主题架构图和经过筛选的公开证据图示。
- 在仓库许可证和包元数据中明确项目自有代码与文档采用 Apache-2.0。引入的 iOS MCP、iCTRL 和保留的 REA 材料继续保留各自声明。

## 指定设备的结果与限制

| 设备 | 已测的选定范围 | 当前限制 |
| --- | --- | --- |
| iPhone XR · iOS 16.1.1 | SSH 包／沙盒采集、Frida、iOS MCP 和 iCTRL；Notes、Calculator、Translate、Clock 的选定分析／复刻路径；最近一次状态对齐的 Counter 对照通过。 | 可选的开发者文件列表会返回 `ConnectionTerminatedError`；SSH 采集可用。 |
| iPhone 14 · iOS 17.3.1 | 当前代码采集 Calculator、四条经 iOS MCP 的原版／复刻版运算断言、五组轻微差异截图，以及原版 App 的选定按钮 Frida 跟踪。 | 额外的 iCTRL 复刻版多步重放两次在等号处报 `malformed HTTP response`；稳定性未获证明。 |
| iPhone 11 · iOS 26.0.1 | USB/SSH 采集、iCTRL 和 iOS MCP 界面、Frida 附加、审阅过的 Calculator 与 Clock 报告、签名独立 App，以及选定运算／秒表成对检查。 | Instruments 新启动后 iOS MCP 可能得到黑色 App 区域；已观察案例的有界恢复通过，长期稳定性未知。 |

重启／重新越狱后的持续可用性、第二台实体 Mac 从零配置手机、陌生 App 自主探索、服务端行为和完整视觉／功能等价仍未验证。有些示例改自现有源码，不能据此声称从零生成新 App。准确边界见[当前状态](../current-status.zh-CN.md)。

本版候选通过 **342 项本地单元测试**和隔离 wheel 构建／安装检查。上述真机结果来自已保存的指定设备验证记录；这轮打包没有重跑每条手机流程。

## 安装

检出这个标签，运行 `sh scripts/bootstrap-macos.sh`，再按[首次概览](../../README.zh-CN.md#从这里开始)和[完整安装指南](../setup.zh-CN.md)操作。附件 `copyapp-0.1.1-py3-none-any.whl` 安装 Mac CLI。手机服务和构建／签名路径需分别配置。原始 IPA、沙盒数据、完整截图和密钥只留在被忽略的本地 `cases/`，不作为发布附件。
