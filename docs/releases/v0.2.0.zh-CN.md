# Copy APP v0.2.0

[English](v0.2.0.md) · 简体中文

本版在保留**越狱 iOS** 工作流的同时，新增通过 **ChatComputer 分析和独立复刻
macOS App 选定行为**的支持。以 GitHub 正式版本发布，取代 v0.2.0-beta.1；macOS 支持仍为实验性。
相较 beta.1 仅更新版本元数据和文档，运行行为及实测边界不变。v0.1.2 为上一版仅支持 iOS 的版本。

## 本版改动

- 独立 `copyapp mac` 命令：准确虚拟 Mac／App 身份、有界采集器和 AX、arm64 与
  Mac Catalyst 包采集、流程发现、带引用的行为报告、独立构建安装、成对检查、完整视觉
  审阅及选定交付。
- Apple Silicon Mac 上通过 ChatComputer 使用电脑；当前 Codex／Claude Code 会话
  完成解释与实现，不启动嵌套 Agent 或 ChatComputer 模型循环。
- 快照元数据／重连证据、未知结果保留，以及快照前暂停采集器自身轮询 30 秒的有界机制。
  真人接管后拒绝工具输入，不自动重发未知结果的操作。
- Agent 复刻默认 **80 分、最多三轮**；核心选定行为与逐图审阅仍须通过。评分、已知能力
  覆盖和选定流程通过率分开；旧严格交付及独立父流程规则保持不变。
- 新 `copyapp copy` 任务默认输出到 `output/<bundle>-<UTC>-<unique-id>/`，分开
  `project/` 和 `evidence/`；支持 `--output-dir`、旧显式路径与固定旧目录续跑。
  Mac Agent 显式沿用布局，底层命令仍需子目录参数，尚无 `mac copy` 包装命令。
- 双语 README 和网站提供两个平台可直接交给 AI 的任务。[Stocks 示例](../../examples/macos/Stocks/README.md)
  包含独立 AppKit 源码、三条流程脚本和本地构建入口；行情／新闻为明确标注的离线示例，
  不含实时服务或 Apple 资产。同时包含[独立编辑器](../../examples/macos/IndependentEditor/README.md)
  与[自有原版样例](../../examples/macos/BehaviorFixture/README.md)。

## 验证与边界

本版通过 **410 项本地测试**及隔离 wheel 构建／安装检查。保留 iOS 命令与 v1 历史
证据验证，不声称新增 iPhone 真机执行；旧指定设备结果见[当前状态](../current-status.zh-CN.md)。

指定 Mac 证据来自 ChatComputer 0.9.11 (43)、macOS 客体 27.0.1 (26A434)，及
Apple Silicon macOS 27.0 (26A428) 宿主：

- 两个样例各三条流程、各三轮，每个 **9/9** 成对行为检查通过。自有编辑器完成
  **7/9 已知能力**严格选定交付，285 对完整截图审阅，零明显、285 轻微差异。
- Stocks 的 207 对完整截图保留 **207 项明显差异**；用户后来要求的离线原型评分
  **81/100 达到 80 档**。它不是客观相似度、严格交付或能力覆盖率。
- 同一客体原版／复刻编辑器二进制在指定实体 Mac 完成三项行为手动复验；另有真实人工
  接管／输入拒绝、用户明确授权 Agent 代点交回，以及受控真实输入回复丢失记录。
- 一次暂停轮询后的取快照／恢复，保留相同编辑器进程、未保存 Unicode 文本和换行状态，
  并验证中间修改后恢复原状态。安全快照保留，早期失败案例保持失败。

这些真实记录早于最终版本元数据更新；采集器运行逻辑未改变，发布版采集器由原生测试重新构建。
详见[实施账本](../macos-implementation-plan.md)和[恢复说明](../macos-recovery.md)。暂停不覆盖
其他客体 I/O，宿主共享目录和外部服务不回滚；不声称任意 Mac 兼容、整 App 等价、Mac 深层
函数分析、完整 App 数据或实时股票服务。

## 使用

从 [README 的 AI 任务](../../README.zh-CN.md#从这里开始)开始，或检出此标签并执行
`sh scripts/bootstrap-macos.sh`。客体权限、手机信任和签名可能需要首次配置。
`copyapp-0.2.0-py3-none-any.whl` 安装 CLI，`SHA256SUMS` 提供校验和；Skill 和样例
需要源码检出。wheel 不包含设备／VM 证据、凭据、Apple 安装包或已签名 App 产物。
