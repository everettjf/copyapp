# Copy APP v0.1.16：系统 Notes 选定流程实测

[English](v0.1.16.md) · 简体中文

本版在越狱 iPhone XR / iOS 16.1.1 上完成一次系统 Notes 端到端实测。Copy APP 发现三条本地账户流程，获取安装包，记录限定范围的 Frida 调用，生成精确二进制的 Hopper 证据，产出审阅报告，构建并安装独立 [UIKit 复刻版](../../rebuild/NotesClone/README.zh-CN.md)，完成三条原版/复刻版脚本对照。三组截图均审阅为轻微差异；具体范围与缺口见[实测记录](../notes-xr-workflow.zh-CN.md)。

实测发现砸壳阶段的问题：系统 Notes 索引中的 Mach-O 已未加密，默认流程却仍启动手机端助手并超时。现在该阶段会验证来自精确设备的原包快照；对于未加密包跳过助手，在恢复清单和 `copyapp verify` 中明确区别于真正的加密包恢复。原有加密包流程继续由回归测试覆盖。

原版在新建笔记后会恢复编辑页，影响搜索脚本的起始状态。本次保存明确的界面复位操作并在同一案例中续跑；最终截图前也关闭了首次出现的 Tags 提示。这些是案例准备步骤，不能把新启动当作清空导航。复刻版覆盖本地文件夹、纯文本输入及自身 JSON 持久化、文本搜索；不覆盖 iCloud、富文本、附件、共享、锁定、系统 Notes 全部内部原理或 iOS 17 原版 Notes。

验收：**322 项 Python 测试通过**；Notes 父案例及报告、安装、成对对照、视觉审阅、交付子案例均通过 `copyapp verify`。wheel 已隔离安装到 `/tmp`，确认导入版本 0.1.16，并用其校验父案例。XR 安装的复刻 IPA SHA-256 为 `4e9d8c53842b2c3f5356498096b5de9302b4533b1d43548f3856642f88fbeee4`。设备案例及 IPA 均为本地忽略提交的产物，不进入 wheel。
