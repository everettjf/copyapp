# Copy APP v0.2.0

[English](v0.2.0.md) · [简体中文](v0.2.0.zh-CN.md)

This release adds **macOS App analysis and selected-behavior rebuilding through
ChatComputer**, alongside the existing **jailbroken iOS** workflows. It is the
latest GitHub release, superseding v0.2.0-beta.1. macOS support remains experimental.
The change from beta.1 updates release metadata and documentation; runtime behavior
and the measured acceptance scope are unchanged. v0.1.2 is the previous iOS-only release.

## What's included

- Separate `copyapp mac` commands for an exact virtual Mac and App: bounded
  collector/AX observations, arm64 and Mac Catalyst package acquisition, flow
  discovery, cited behavior reports, independent builds/installations, paired
  checks, full screenshot review and selected delivery.
- Computer use through ChatComputer on an Apple Silicon Mac. The current Codex
  or Claude Code session performs interpretation and implementation; no nested
  agent or ChatComputer model loop is needed.
- Snapshot metadata/reconnect cases, unknown-result preservation and a bounded
  30-second collector-polling pause around snapshot operations. Human takeover
  refuses subsequent input; uncertain actions are not automatically retried.
- Agent-led fidelity defaults to a reviewed **80/100 grade and three cycles**.
  Core selected behavior and complete image review remain required. Grades,
  known-capability coverage and selected-flow pass rate stay separate. Historical
  strict delivery and standalone parent workflows retain their existing rules.
- New `copyapp copy` jobs default to `output/<bundle>-<UTC>-<unique-id>/`, with
  sibling `project/` and `evidence/`. `--output-dir` overrides the root; legacy
  explicit paths remain supported. Resume pins the previous directory. Mac
  agent-led jobs use this layout with explicit child paths; there is no `mac copy`
  wrapper.
- Bilingual README/site entry points with copyable AI tasks for both platforms.
  The [Stocks source example](../../examples/macos/Stocks/README.md) includes
  independent AppKit code, playbooks and a local build script. Its prices/news
  are illustrative offline content, with no live market service or Apple assets.
  The [independent editor](../../examples/macos/IndependentEditor/README.md) and
  [owned fixture](../../examples/macos/BehaviorFixture/README.md) are also included.

## Validation and limits

The release passes **410 local tests** and an isolated wheel build/install check.
Existing iOS commands and v1 evidence validators are preserved; this release does
not claim new physical-iPhone runs beyond the named saved results in
[current status](../current-status.md).

Named Mac evidence uses ChatComputer 0.9.11 (43), macOS guest 27.0.1 (26A434) and
an Apple Silicon macOS 27.0 (26A428) host:

- Each of the two samples passes three selected flows across three rounds:
  **9/9 comparisons per sample**. The owned editor has a strict selected delivery
  of **7/9 known capabilities**; all 285 image pairs were reviewed, with zero
  major and 285 minor differences.
- Stocks' 207 full image pairs retain **207 major differences**. Its later
  requested offline-prototype milestone scores **81/100** against target 80;
  that is neither objective similarity nor strict delivery or capability coverage.
- Same guest original/rebuilt editor binaries pass a three-behavior manual
  recheck on one physical Mac. Actual human takeover/refusal, explicitly
  authorized agent hand-back and controlled real-input reply loss have separate
  records.
- One quiesced take/restore retains the running editor's exact process identity,
  unsaved Unicode text and wrapping through an intervening state change. A safety
  snapshot is retained. Earlier failed snapshots remain failed and preserved.

These live records precede the final release-version metadata update; collector
runtime logic is unchanged. The release collector is rebuilt by the native tests.
See [the ledger](../macos-implementation-plan.md) and [recovery limits](../macos-recovery.md).
Other guest I/O, shared folders and external services are not quiesced or rolled
back. Arbitrary-Mac compatibility, whole-App parity, deep Mac function analysis,
complete App data and a live Stocks service are not established.

## Install

Use the [README AI tasks](../../README.md#start-here), or check out this tag and
run `sh scripts/bootstrap-macos.sh`. Mac guest permissions, phone trust and
signing may require initial setup. `copyapp-0.2.0-py3-none-any.whl` installs the
CLI; `SHA256SUMS` records its checksum. Keep the source checkout for skills and
examples. No device/VM evidence, credentials, Apple packages or signed app products
are included in the wheel.
