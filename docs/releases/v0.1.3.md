# Copy APP v0.1.3: new-source Calculator validation on iOS 17

[English](v0.1.3.md) · [简体中文](v0.1.3.zh-CN.md)

This release builds on the [v0.1.2 two-device validation](v0.1.2.md). The tested scope is selected-flow analysis and rebuilding on iPhone XR / iOS 16.1.1 / Dopamine rootless and iPhone 14 / iOS 17.3.1 / Relaxin RootHide. The iOS 16 and 17 fixture checks, current SQLite row comparisons, encrypted-package pilots, and device setup remain described in the earlier release records.

## New in this release

The [iOS 17 Calculator pilot](../ios17-calculator-fresh-from-report.md) now includes a separate, newly authored UIKit project at [`rebuild/CalculatorIOS17Fresh`](../../rebuild/CalculatorIOS17Fresh/README.md). Its selected `7 + 8 = 15` flow derives from the reviewed Calculator deep report. Three more flows—decimal addition, negative addition and percentage—were observed on the same phone's current UI. They do not inherit the deep report's static or Frida claims.

The project was built, development-signed, installed and checked on the iPhone 14. An initial negative-result mismatch (`-7` versus the original `−7`) was corrected in build 0.1.1 (2). The formal four-flow paired check then passed final UIKit text assertions on both Apps for `15`, `0.3`, `−7` and `0.5`. All five saved screenshot pairs were manually reviewed as minor differences, principally result font weight and the system return-to-App label. The tracked feature specification and original/rebuilt playbooks allow the selected checks to be rerun. The signed IPA, screenshots and raw device evidence are intentionally kept in local, Git-ignored `cases/`; the public release contains source, scripts and review records.

## Validation and limits

The 309-test Python suite passed for this release. It changes the sample UIKit source, playbooks, documentation and package version; its new-source build, install, four-flow device comparison and visual-review cases passed their relevant gates. The `copyapp-0.1.3-py3-none-any.whl` metadata and CLI entry point were checked; wheel SHA-256: `2b023231f956c22c8fef40dd72540c8940ab4d6b1dec27f67c26a63e1c65a2f9`.

The result validates the named devices and selected flows. It does not establish whole-App Calculator equivalence, reliable cloning of an unfamiliar App, an autonomous Claude CLI run, the share extension's user-facing invocation, or iOS 26 support. The packaged RootHide Frida 16.1.4 server still fails on original Calculator; the pinned 17.23.3 sidecar is the verified trace route. RootHide encrypted-package recovery uses mobile SSH because the installed Frida process cannot supply root `root-run`.
