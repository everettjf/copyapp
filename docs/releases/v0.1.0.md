# Copy APP v0.1.0

[English](v0.1.0.md) · [简体中文](v0.1.0.zh-CN.md)

Copy APP connects two stages: evidence-backed analysis of an installed iOS App on a jailbroken phone, then an independent runnable App with measured coverage. This release records selected-flow validation on three phones. It does not recover original source or claim whole-App equivalence.

| Phone | iOS / jailbreak | Verified selected scope |
| --- | --- | --- |
| iPhone XR | 16.1.1 / Dopamine rootless | USB, SSH, Frida, iOS MCP and iCTRL; reviewed Notes and other selected reports; independent App installation and paired behavior checks. |
| iPhone 14 | 17.3.1 / Relaxin RootHide | The core channels, pinned Frida 17.23.3 sidecar, encrypted package recovery, reviewed Calculator report and signed independent clone checks. |
| iPhone 11 | 26.0.1 / Relaxin RootHide | USB/SSH, personalized developer image and userspace iCTRL, ElleKit and iOS MCP service, Frida attach, reviewed Calculator report, signed independent App installation and one paired `7 + 8 = 15` check. |

The iOS 26 release validation identified a screenshot limitation: iOS MCP can capture a black App area after an Instruments fresh launch, so the passing paired screenshots used iCTRL. The iOS 26 Calculator result is SwiftUI-backed and absent from the bounded UIKit label scan; an explicit screenshot OCR assertion now checks the exact result within a saved, hash-bound screen region. After adapting the existing independent source to the observed iOS 26 layout, the final pair passed visual review with **minor differences** and no major difference. This is report-guided adaptation of existing source, not generation of a new project from scratch. The chosen UIKit method hooks recorded zero calls, so Calculator's SwiftUI input dispatch remains unknown.

## Install

Clone this tag and run `sh scripts/bootstrap-macos.sh`, then follow the [first survey and phone-service setup](../../README.md#start-here). The wheel `copyapp-0.1.0-py3-none-any.whl` contains the Mac CLI. The phone tweak, Theos, Xcode signing, Frida sidecar and credentials are set up separately for the target device. Raw IPAs, screenshots, sandbox data and keys stay in local Git-ignored `cases/` and are not release assets.

The release gate ran the repository test suite and verified the saved iOS 26 report, install, paired check and visual review. Device evidence is scoped to the named configurations and flows. Clean-Mac setup, long-running reliability, unfamiliar-App autonomous discovery, iOS 26 screenshot recovery and broader visual fidelity remain open.
