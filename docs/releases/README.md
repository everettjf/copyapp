# Published releases

[English](README.md) · [简体中文](README.zh-CN.md)

The [GitHub Releases page](https://github.com/everettjf/copyapp/releases) is the authoritative list of published versions and downloadable wheels. The latest release is [v0.2.0](v0.2.0.md) ([Chinese](v0.2.0.zh-CN.md)), supporting jailbroken iOS and macOS. Earlier releases remain archived: [v0.2.0-beta.1](v0.2.0-beta.1.md), [v0.1.2](v0.1.2.md), [v0.1.1](v0.1.1.md) and [v0.1.0](v0.1.0.md).

Numbered local development checkpoints were removed from the current documentation tree. Their original commits remain in Git history; they were never installable tags or GitHub Releases. See [current support and validation](../current-status.md) for tested scope and open limits. Future versions will be numbered only when tagged and published.
