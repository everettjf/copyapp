# Copy APP v0.1.17：第一个选定流程里程碑

[English](v0.1.17.md) · 简体中文

这个 patch 版本标记已越狱 iOS 16 和 iOS 17 设备上第一个完成验证的**选定流程**里程碑。Copy APP 能采集有来源的 App 证据、生成审阅后的分析报告、指导独立可运行的 iOS 复刻版，并将同机行为和视觉检查绑定到交付案例。[iPhone XR / iOS 16.1.1 Notes 实测](../notes-xr-workflow.zh-CN.md)与 [iPhone 14 / iOS 17.3.1 Calculator 工作](../ios17-calculator-fresh-from-report.zh-CN.md)界定了已测范围；它们不能证明任意 App 的自主复刻或全部功能、视觉等价。

新增 `coverage-plan`：固定人工审阅的已知用户能力清单、重要性权重、选定流程、延后／受阻项和未知领域；修订时保留旧目标。`coverage-delivery` 绑定一个或多个通过校验的真机 `agent-delivery` 案例和逐项审阅结论，分别报告目标百分比、选定阶段完成率、已知能力实证覆盖率。若关联流程缺少通过的行为断言，或没有完成视觉审阅，或存在重大差异，该能力不能标记为已验证。分母定义及命令示例见[方法指南](../coverage-targets.zh-CN.md)。

验收：**324 项 Python 测试通过**。使用已保存的 XR Notes 报告、复刻计划与真机交付进行本地离线演练，两种新覆盖案例均通过 `copyapp verify`。其中五项能力清单只是有界示例，不能解释为整个 Notes 的覆盖估算。iOS 16/17 的来源绑定案例仍是这个里程碑的真机证据；本 patch 没有宣称对所有路径重新做过真机运行。

**下一阶段：**iOS 26 的设备搭建与证据化验证。本版尚未测试 iOS 26。陌生 App 的通用自主发现与新源码生成、账号和服务端行为、完整 App 等价仍有待完成。
