# Copy APP v0.1.8: first-use gates and four-way App checks

[English](v0.1.8.md) · [简体中文](v0.1.8.zh-CN.md)

The [two-device verification matrix](../two-device-verification-matrix.md) now covers two more original-App flows on the iPhone XR / iOS 16.1.1 and iPhone 14 / iOS 17.3.1. The **same committed Translate script** displayed exact synthetic `copyappfixture` input through iOS MCP and iCTRL on both phones. The **same committed Clock script** started and stopped a nonzero Stopwatch through both backends on both phones. All eight new flow-capture cases pass `copyapp verify`; screenshots and UIKit/accessibility text corroborate their visible outcomes. On iOS 17, Translate automatically displayed a result after input; its semantic quality was not assessed, and no clone of that result was tested.

The XR's earlier Translate iOS MCP failure was reproduced with its original lower tap `(207,320)`: text dispatch returned success while the screenshot showed a caret but no keyboard or text. The new shared script taps the visible placeholder at `(100,201)`, shows the keyboard and passes. This is a focus-sensitive screen interaction, not a device-wide text-input failure. The old failed case is retained; no backend replay is silently retried.

Before first use on iOS 17, Translate and Clock launch requests returned errors while SpringBoard presented each App's **Welcome / Accept & Continue** page. After first-use choices were completed on the test phone, both Apps entered their own foreground processes. Their subsequent `survey --launch` cases passed with matching before/after foreground Bundle IDs. The [first-use guide](../ios17-first-use-gates.md) explains the diagnostic boundary and leaves data choices to the device owner.

The v0.1.7 published wheel was separately downloaded and loaded from an isolated install directory. Fresh v0.1.8 doctor cases `cases/ios16-v018-doctor-20261017/` and `cases/ios17-v018-doctor-20261017/` again found USB, screenshot, developer filesystem, pinned mobile SSH, Frida, iOS MCP and paired iCTRL available on both phones; four saved analysis-to-rebuild parents passed evidence verification again. These artifact and selected-flow checks still do not prove whole-App equivalence, unfamiliar-App autonomous generation, background Clock behavior, all Translate features, standalone Claude CLI operation or iOS 26 support.

Release QA: **310 unit tests passed**. Eight new flow captures, the retained failed-tap control, two post-onboarding surveys and both v0.1.8 doctor cases passed `copyapp verify`. The `copyapp-0.1.8-py3-none-any.whl` metadata, console entry point and isolated install were checked; SHA-256: `cec0b0967d6d01beb781648eb53c811ebae356a9cb199f678eaa320da23f41c5`.
