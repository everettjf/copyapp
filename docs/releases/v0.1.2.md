# Copy APP v0.1.2

[English](v0.1.2.md) · [简体中文](v0.1.2.zh-CN.md)

This patch fixes the iCTRL XCTest-session lifetime fault seen in iOS 17 paired replays and puts agent-led first use at the front of the README.

## Changes

- Keep one owned iCTRL session through all selected original/rebuilt flows and their immediate view-tree captures. Stop the owned runner before disconnecting its XCTest host so the next command cannot reuse a briefly responsive remnant of that session.
- Preserve a failed result when session cleanup fails. On a lost HTTP reply, explain that action completion is unknown and the caller must inspect logs and UI before retrying; touches are not automatically replayed.
- Add the repository's `copyapp-start` skill and copyable Codex / Claude Code tasks in the English and Chinese READMEs. The agent can clone the repository, check the Mac, identify the exact phone/app and continue into the requested survey, analysis or rebuild. Manual CLI instructions remain available.

## Validation and limits

On the named iPhone 14 / iOS 17.3.1 / Relaxin RootHide, two independent production-command runs each passed four original/rebuilt Calculator flows: `15`, `0.3`, `−7` and `0.5`. Together they issued 88 labelled tap commands. Runner PID was 0 after each run. All ten screenshot pairs were reviewed, with minor font, position and symbol differences retained. The original failed attempts and controlled experiments remain in ignored local cases.

The release passes **346 local unit tests** and an isolated wheel build/install check. The wheel check requires the new runner-stop module to be packaged. The named-device results are saved evidence from the fix verification; this release pass does not repeat every phone workflow.

The changed cleanup has **not** been revalidated on the named iOS 16 or iOS 26 phones. Reboot/rejailbreak durability, long-running stability, second-physical-Mac onboarding and unfamiliar-app autonomous discovery remain open. Earlier named-device results and the iOS 26 black-frame recovery boundary are preserved in [current status](../current-status.md). Selected-flow success does not establish whole-app or server-side equivalence.

## Use

Give the [README task](../../README.md#start-here) to Codex or Claude Code running locally on your Mac, or check out this tag and run `sh scripts/bootstrap-macos.sh`. Phone trust, initial permissions and signing access may require user participation.

The attached `copyapp-0.1.2-py3-none-any.whl` installs the Mac CLI; `SHA256SUMS` records its checksum. Keep a source checkout for repository skills and optional source-built tools. The wheel does not contain phone tweaks, Theos, signing assets, device evidence or credentials. Historical [v0.1.1 notes](v0.1.1.md) remain unchanged.
