# Copy APP v0.1.0：双机发布验收

[English](v0.1.0.md) · [简体中文](v0.1.0.zh-CN.md)

首个版本支持**选定流程**的证据采集、分析和独立 App 复刻验收，不承诺恢复原始源码或复现任意 App 的全部功能。2026-10-17 的实测原始包、截图、沙盒文件和配对资料只保存在本地、被 Git 忽略的 `cases/` 中。

使用该版本时，克隆仓库、执行 `git checkout v0.1.0`，再按 [Mac 安装步骤](../../README.zh-CN.md#新用户安装与第一次运行)配置。此标签构建出的 wheel 名为 `copyapp-0.1.0-py3-none-any.whl`；安装 wheel 不会自动安装手机端 tweak 或签名工具。

| 验收项 | iPhone XR · iOS 16.1.1 · Dopamine rootless | iPhone 14 · iOS 17.3.1 · Relaxin/RootHide |
| --- | --- | --- |
| 设备通道 | 精确 USB 身份、截图、DVT、mobile SSH、Frida、iOS MCP、iCTRL 可用 | 同样八项可用；Frida 使用固定版本 17.23.3 独立服务 |
| App 证据 | 新版已知源码夹具、Framework、分享扩展、静态索引和沙盒索引已采集校验 | Apple Development 签名夹具及相同类型组件已采集校验 |
| 安装 | 新版夹具通过 TrollStore 安装，并通过新的计数器界面脚本 | 原版与独立复刻版经 USB 安装，安装案例校验通过 |
| 界面与复刻 | Counter、Notes、Catalog 三流程经 iCTRL 正式成对对照 | 原版三流程分别通过 iOS MCP 与 iCTRL；复刻版三流程通过 iOS MCP |
| 逐图审阅 | 五组截图的选定内容一致，仅系统顶部返回应用名称存在轻微差异 | 对齐旧测试数据后，五组截图同样仅有该轻微差异 |
| 加密包 | 先前 DeepSeek 整包恢复案例再次校验通过 | 先前 Remoboard 主程序和键盘扩展恢复案例再次校验通过 |

正式夹具案例为 `ios16-fixture-release-rebuild-check-20261017` 与 `ios17-fixture-release-rebuild-check-v2-20261017`；逐图审阅为 `ios16-fixture-release-visual-review-20261017` 与 `ios17-fixture-release-visual-review-v2-20261017`，均通过 `copyapp verify`。夹具覆盖 SwiftUI/UserDefaults、UIKit/SQLite 和独立 Framework；分享扩展已打包和索引，但本轮未触发其用户交互。笔记计数增加不等同于本轮已核对每条 SQLite 行正文。XR 另有 Calculator、Translate 选定流程案例；iPhone 14 另有 Calculator 的运行时跟踪、审阅报告和单流程交付。

本轮修复了分享扩展缺少 `CFBundleDisplayName` 导致 iOS 17 拒绝安装，以及主 App 缺少 `UILaunchScreen` 导致画面缩在中央、iOS MCP 点击坐标偏移的问题。修复后的包已在两台手机安装并验证。双机同时连接时，每台应使用单独固定的 SSH 主机密钥文件和端口，所有命令明确传 `--udid`；新诊断现在能指出密钥混用，而不是误报 OpenSSH 未就绪。XR 的 TrollStore `install` 路径需要先打开相应 USB SSH 转发。

本地 308 项单元测试通过。XR 的 iOS MCP 新启动回退曾保留上一页，失败案例已保留；返回首页后继续，正式对照使用 iCTRL 的终止/重启路径。iOS 17 曾在原版仍运行时出现更新停滞，先停止 App 后使用同一签名 IPA 重试，安装案例通过。RootHide 的整包恢复使用 mobile SSH；原有 Frida 16.1.4 服务不适用于此次 Calculator 跟踪，独立 17.23.3 服务已通过；通用 root `root-run` 仍不可用。

iOS 26、其他越狱组合、整 App 等价、未观测的服务端行为以及未经审阅的陌生 App 自动复刻仍未验证。发布的可移植产物是源码和 Python wheel；手机端包需按目标设备越狱工具链或 Apple Development 签名自行构建。测试 IPA 和设备原始证据不会公开。
