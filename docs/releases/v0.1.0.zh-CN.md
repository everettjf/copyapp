# Copy APP v0.1.0

[English](v0.1.0.md) · [简体中文](v0.1.0.zh-CN.md)

Copy APP 包含两个阶段：对越狱手机上已安装的 iOS App 做有证据的分析，再实现可运行的独立 App，并衡量选定功能的覆盖范围。此版本在三台手机上完成了选定流程验证；不承诺恢复原始源码或实现整个 App 的功能等价。

| 手机 | iOS／越狱 | 已验证范围 |
| --- | --- | --- |
| iPhone XR | 16.1.1／Dopamine rootless | USB、SSH、Frida、iOS MCP、iCTRL；Notes 等选定流程的审阅报告、独立安装和成对行为检查。 |
| iPhone 14 | 17.3.1／Relaxin RootHide | 核心通道、固定版本 Frida 17.23.3 独立服务、加密包恢复、Calculator 正式报告及签名独立复刻版检查。 |
| iPhone 11 | 26.0.1／Relaxin RootHide | USB／SSH、个性化开发者镜像与 userspace iCTRL、ElleKit 和 iOS MCP 服务、Frida 附加、Calculator 正式报告、签名独立 App 安装，以及一条 `7 + 8 = 15` 成对流程。 |

[iOS 26 真机记录](../relaxin-roothide-iphone11-ios26.md)说明了截图限制：通过 Instruments 重新启动 App 后，iOS MCP 可能只截到黑色 App 区域，因此通过的成对截图使用 iCTRL。iOS 26 Calculator 的结果文本由 SwiftUI 支撑，未出现在有界 UIKit 标签扫描中；新增的显式截图 OCR 断言在保存并绑定哈希的屏幕区域内核对精确结果。把既有独立源码按 iOS 26 真机界面调整后，最终成对截图审阅为**轻微差异**，没有重大差异。这是依据报告和实测界面改造既有源码，并非从零生成新工程。所选 UIKit 方法挂钩没有命中，SwiftUI 输入分发仍未确定。

## 安装

克隆此标签并运行 `sh scripts/bootstrap-macos.sh`，然后按 [首次 USB 检查及手机服务安装](../../README.zh-CN.md#开始使用)操作。`copyapp-0.1.0-py3-none-any.whl` 只包含 Mac CLI；手机端 tweak、Theos、Xcode 签名、Frida 独立服务和凭据仍需按目标设备单独配置。原始 IPA、截图、沙盒数据和密钥留在 Git 忽略的本地 `cases/`，不会成为 Release 附件。

发布前运行了仓库测试，并验证 iOS 26 的正式报告、安装、成对检查和逐图审阅。结论只针对列出的设备配置与流程。全新 Mac 搭建、长期可靠性、陌生 App 自主发现、iOS 26 截图恢复和更广范围的视觉一致性仍待完成。
