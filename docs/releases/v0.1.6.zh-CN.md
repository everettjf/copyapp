# Copy APP v0.1.6：完成 iOS 16 与 17 的选定流程验收

[English](v0.1.6.md) · [简体中文](v0.1.6.zh-CN.md)

本版重新检查了两台已连接越狱机：iPhone XR / iOS 16.1.1 / Dopamine rootless，以及 iPhone 14 / iOS 17.3.1 / Relaxin RootHide。两份新的 `copyapp doctor` 案例都显示 USB 身份、截图、开发者文件系统、固定主机密钥的 mobile SSH、Frida、iOS MCP 和已配对 iCTRL 可用。本地证据分别在 `cases/ios16-v016-doctor-20261017/` 和 `cases/ios17-v016-doctor-20261017/`，均通过 `copyapp verify`。结论只适用于这两台设备及其当前配置。

XR 上此前完成的 [Calculator 当前 Agent 父案例](../../cases/calculator-current-auto-workflow-20261016/manifest.json)及 Clock 父案例再次通过校验。Calculator 父案例覆盖三条选定运算路径，包含有来源报告、独立安装的复刻版、三条通过的成对末端断言和三对审阅为轻微差异的截图。[v0.1.5 发布记录](v0.1.5.zh-CN.md)另行记录两机已知源码夹具的文本分享扩展及 Counter、Notes、Catalog 回归。

iPhone 14 新增一条完成的[四流程 `copyapp copy` 父案例](../../cases/ios17-calculator-current-parent-20261017/manifest.json)。它采集 Calculator 1.0.0 已安装包与有界沙盒索引，重放四条原版竖屏流程。Frida 在每个选定点击窗口记录一次 `CalculatorModel::buttonPressed:` 当前 IMP 和原始静态入口命中；有界 ARM64 汇编显示输入分发结构，但没有恢复完整算术实现。当前 Coding Agent 审阅事实草稿，产出[有来源的报告与功能规格](../../cases/ios17-calculator-current-parent-20261017/analysis-agent/reviewed-report/report.md)，再安装此前已编写、使用开发签名的独立 Calculator 工程。新的同机对照中，四条末端 UIKit 精确结果 `15`、`0.3`、`−7`、`0.5` 全部通过。五对截图逐张审阅均有轻微的结果字体或系统返回标签差异，没有重大差异。报告、安装、对照、视觉审阅、交付和父案例均通过 `copyapp verify`。

iOS 17 复刻源码写于此前的[新源码试验](../ios17-calculator-fresh-from-report.zh-CN.md)，早于这条父案例。父案例证明 `--agent-provider current` 能在分析与复刻交接处恢复并使用已有源码；它不证明一句话从零生成陌生 App。本次 Calculator 运行选用 `--no-decrypt --no-network`，且该系统 App 主程序未加密；RootHide 加密包恢复另有记录。两机案例都不证明整 App 等价、所有 UI 状态、所有保护机制、iOS 26 支持或独立 Claude CLI 执行。

本版调整包版本和验收文档；CLI 行为及设备端安装包与 v0.1.5 相同。309 项 Python 测试通过；wheel 元数据与 `copyapp` 命令入口已核对。`copyapp-0.1.6-py3-none-any.whl` 的 SHA-256 为 `50c925916fb83a35c0265eeffbd14c3430dc1117f2f79284ee2c8b407ec9907f`。
