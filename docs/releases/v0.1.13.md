# Copy APP v0.1.13: embedded-framework tracing and two-device Podcasts delivery

[English](v0.1.13.md) · [简体中文](v0.1.13.zh-CN.md)

Static Frida binding now accepts a Mach-O inside an embedded `.framework` and matches the loaded module by its complete path relative to the enclosing `.app`. This repairs a gap found while tracing `PodcastsStoreUI.SearchLandingCell`; the main-executable path remains supported. A targeted regression test checks path generation, and the XR recorded 12 current-IMP plus 12 static-offset initializer hits in a Search tap window. The iOS 17 hook attached to the correct framework but recorded zero hits in its sampled Search window, which does not prove the class was unused.

Apple Podcasts now has separate source-linked reviewed reports and analysis deliveries on iPhone XR / iOS 16.1.1 / Dopamine rootless and iPhone 14 / iOS 17.3.1 / Relaxin RootHide. After those reports, the current agent wrote a new [independent UIKit project](../../rebuild/PodcastsFreshProbe/README.md), built it with Xcode 27, and installed it on both phones through their respective TrollStore and Apple Development signing paths. Each phone passed 3/3 original-versus-clone Library, Search and Listen Now page-title checks. The six screenshot pairs were reviewed: XR Search has a major illustration/control gap; all three iOS 17 pairs have major gaps, including missing account-specific content. Both verified deliveries correctly report `selected_behavior_verified_visual_gap`. [Detailed evidence and limits](../podcasts-two-device-report-rebuild.md).

This release establishes selected analysis, embedded-framework tracing, build, installation and navigation checks on the two named configurations. It does not establish complete Podcasts functionality or visual fidelity, autonomous zero-shot source generation, an independent Claude CLI run, or iOS 26 support. The Podcasts main executables are unencrypted and do not retest decryption. No private phone case data, signing material or IPA is published.

Release QA: **315 unit tests passed**, including the loopback HTTP fixture. The isolated wheel loaded as version **0.1.13** with a callable CLI entry. Wheel SHA-256: `2475e591ccf9b9026ac87a9928daf7a5a048a16fb5995c52ee9624192f063590`.
