# iOS 16 and 17 verification matrix

[English](two-device-verification-matrix.md) · [简体中文](two-device-verification-matrix.zh-CN.md)

This matrix separates a working transport from a visible App outcome. The two devices are iPhone XR / iOS 16.1.1 / Dopamine rootless and iPhone 14 / iOS 17.3.1 / Relaxin RootHide. Local `cases/` evidence is Git-ignored and must be verified on the testing Mac with `copyapp verify <CASE>`; the committed playbooks are reusable without private device data.

| Capability | XR / iOS 16 | iPhone 14 / iOS 17 | Limit |
| --- | --- | --- | --- |
| USB, screenshot, developer filesystem, pinned mobile SSH, Frida, iOS MCP, paired iCTRL | All available in `cases/ios16-v016-doctor-20261017/` | All available in `cases/ios17-v016-doctor-20261017/` | One current configuration per phone; an available probe alone is not an App behavior check. |
| Package, static and bounded sandbox evidence | Completed Calculator current-agent parent: `cases/calculator-current-auto-workflow-20261016/` | Completed Calculator current-agent parent: `cases/ios17-calculator-current-parent-20261017/` | Calculator build and selected paths only; no entire live data snapshot. |
| Encrypted App analysis | DeepSeek/Kimi full-package recovery cases in the XR release records | Remoboard main App and keyboard extension recovery in `docs/relaxin-roothide-iphone14.md` | Analysis IPAs lose original signatures; other protection methods are not covered. |
| Selected report → independent App → same-device check | Calculator parent: 3/3 results, three reviewed screenshot pairs | Calculator parent: 4/4 results, five reviewed screenshot pairs | Each clone source existed before its cited parent run; whole-App equivalence and zero-shot generation are unverified. |
| Optional direct Hopper decompilation | Integrated fixture UI/Frida/candidate/Hopper investigation and cited report in `cases/fixture-counter-hopper-investigation-v2-20261016/` | A completed `--analysis-provider hopper-direct` Calculator `copy` parent in `cases/ios17-hopper-current-parent-20261017/` joins one traced original flow, Hopper pseudocode, reviewed report, signed independent clone, a passing paired result and two reviewed screenshots | One selected entry and flow. The source predated the parent; pseudocode is interpretation, not original source or full arithmetic recovery. |
| Two UI backends: swipe-to-delete | The **same committed** `playbooks/ios17-calculator-delete-digit.json` showed `98 → 9` through iOS MCP and iCTRL in `cases/ios16-calculator-gesture-{iosmcp,ictrl}-v016-20261017/` | Same script showed `98 → 9` through both backends in `cases/ios17-calculator-gesture-{iosmcp,ictrl}-20261017/` | One portrait left swipe, one numeric state; gesture RPC success was corroborated by before/after screenshots and final UIKit text. |
| Two UI backends: synthetic text input | The **same committed** `playbooks/ios17-safari-synthetic-address-input.json` displayed `copyapp-fixture-hello` in Safari's address field through both backends in `cases/ios16-safari-text-{iosmcp,ictrl}-20261017/` | Same script and visible text through both backends in `cases/ios17-safari-text-{iosmcp,ictrl}-20261017/` | No search was submitted. This does not prove every field or App accepts text. XR Translate still has a separately saved iOS MCP failure. |
| Known-source fixture share extension | Exact synthetic text receipt and Counter/Notes/Catalog regressions in [v0.1.5](releases/v0.1.5.md) | Same | One plain-text item; other item types and unrelated extensions are unverified. |

The Safari result narrows the earlier XR Translate finding: iOS MCP text input is **not globally broken on XR**. Its failure to display `hello` in Translate remains an App/field-specific unresolved case; use the verified iCTRL path for that Translate flow. On iOS 17, an iOS MCP launch of `com.apple.Translate` returned a launch failure in `cases/ios17-translate-entry-survey-20261017/`; no iOS 17 Translate behavior claim follows from the Safari check.

Remaining product-level gates are autonomous discovery and new source generation for an unfamiliar App, a standalone Claude CLI run, broader App state and server behavior, and full sandbox interpretation. These are not implied by green doctors, passing selected flows or a release tag. iOS 26 is outside this two-device matrix.
