# Selected macOS presentation assets

- `dual-platform.svg` is a project-authored workflow illustration, shared byte-for-byte with the website. Its Mac chart is conceptual, not a screenshot or a market feed.
- `stocks-demo.jpg` is an unmodified application-window capture of the independently built `examples/macos/Stocks` app running on the host Mac. It shows AAPL details, local watchlists and explicitly labelled illustrative offline values. The capture contains no desktop, terminal, account, original Apple app or sandbox data. The small sharing indicator is the host capture UI.

This is a presentation of the source example, not a new guest comparison, proof of full behavior reconstruction or a live financial service. Existing named behavioral/visual checks and remaining differences stay in the [acceptance ledger](../../macos-implementation-plan.md). The website uses an identical copy of the selected JPEG.
