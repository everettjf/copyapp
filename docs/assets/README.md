# Public visual assets

Use a bright, approachable palette for Copy APP documentation, the website and
article illustrations. Prefer warm white backgrounds, dark forest text and pastel
mint, sky blue, lavender or peach panels. Keep saturation in small accents rather
than dark backgrounds or neon glows.

| Role | Color |
| --- | --- |
| Page / canvas | `#F8FCF8` or warm white |
| Main text | `#203C35` |
| Secondary text | `#52675A` |
| Primary accent | `#087D44` |
| Supporting accents | `#287AA8`, `#7653B4`, `#AF542B` |
| Panels | `#E5F6EB`, `#E8F5FF`, `#F2EBFF`, `#FFF2E3` |

`readme-architecture.svg` is the shared English, dual-platform architecture.
Keep both platform branches and their measured scope explicit. The concept artwork in
`macos/dual-platform.svg` is mirrored at `web/assets/macos/dual-platform.svg`;
update both copies together. Concept artwork must remain labelled as illustration.

The older social cards and evidence illustrations already use a light palette.
Their original App screenshots are evidence: preserve the source images and use
light surrounding panels. Do not recolor screenshots or imply a different App
appearance or a new device run. Screenshot origins are documented in
`macos/README.md` and the associated evidence records.
