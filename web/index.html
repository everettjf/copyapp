// REVERSE ENGINEERING

Choose your analysis tools.

Two directly integrated decompilers, plus runtime tracing and bounded assembly. Decompilation is optional; the default provider is none.

DECOMPILER / OPTIONAL

Ghidra

Selected-function pseudocode, bounded call relationships, blocks and instruction references.

ghidra-directInstall Ghidra and a matching JDK. Supports function, queue and selected indirect-call investigation.
DECOMPILER / OPTIONAL

Hopper

Selected-function pseudocode and candidate queues through the local Python scripting interface.

hopper-directRequires a local Hopper license and a logged-in macOS GUI session. No REA runtime required.
RUNTIME OBSERVATIONS

Frida

Trace named Objective-C methods and selected entries during bounded UI flows.

trace / flow-capture --methodRequires compatible host/device services. A temporal hit alone does not prove UI causality.
ARM64 DISASSEMBLY

LLVM / Xcode

Bounded assembly windows and unique local direct-call/branch followers with llvm-objdump.

native-disasm / native-queueUses the local Xcode toolchain. Assembly output is separate from decompiler pseudocode.

Built-in package & Objective-C indexesInspect Mach-O load commands, classes, selectors and method addresses without a decompiler.

Encrypted-package recoverySupported jailbreak routes recover device code. Mac offline recovery uses a local FairPlay credential matching the IPA account; first retrieval needs a supported jailbroken phone.

Native-function investigation needs matching code and runtime evidence and primarily serves jailbroken iOS. Standard iOS focuses on UI; Mac uses App-package, AX and UI evidence.

REA is not a runtime dependency. IDA Pro, Binary Ninja and radare2 currently have no direct adapters. Pseudocode is generated evidence, not original source.

// PLATFORM SUPPORT

Two ways for iOS. Plus Mac apps.

Choose by device access and the evidence you need. Continue to independent implementation and flow comparison in each route.

STANDARD / USB + XCTEST

Non-jailbroken iOS

Use signed XCTest, accessibility observations and exact USB screenshots to review behavior, build an independent signed App and compare the same flows. No original IPA, FairPlay credential, SSH or Frida required.

Tested on an inactive-jailbreak iOS 26 sample and an explicit iOS 17 standard regression. A never-jailbroken device has not been separately tested.
